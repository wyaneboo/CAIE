Classical Machine Learning

Classical machine learning turns rows of measurements into predictions or compact descriptions of structure. These models remain exceptionally strong on tabular data, are usually quick to train, and make the central ideas of loss, regularization, generalization, and evaluation visible. This chapter builds those ideas from notation to calculation, then shows where each method succeeds and where its assumptions break.

Learning outcomes
  • Derive and implement linear and logistic regression; explain L1/L2 regularization and contrast their effects on weights.
  • Describe decision trees (Gini/entropy splits); explain bagging, random forests, and boosting; describe SVMs, the kernel trick, and margin maximization; apply k-NN and explain the curse of dimensionality.
  • Implement k-means and explain its convergence and failure modes; describe hierarchical clustering, DBSCAN, GMMs and EM; apply PCA; explain t-SNE/UMAP and their distortions.
  • Calculate accuracy, precision, recall, F1, ROC-AUC, PR-AUC and choose among them; diagnose over/underfitting from learning curves; describe class-imbalance strategies; explain data leakage.

Orientation — read the data before the algorithm

A sample is one case: one patient, loan, image, or experimental run. A feature is a measured input such as age, temperature, or intensity. With \(n\) samples and \(d\) features, place the inputs in the design matrix \(X\in\mathbb{R}^{n\times d}\): row \(i\), written \(x_i^\top\), describes sample \(i\), while column \(j\) contains feature \(j\). A label or target is the answer to predict; collect the targets in \(y\). Regression targets are numerical, while classification targets are categories such as \(y_i\in\{0,1\}\).

The three-way split

The training set fits parameters. The validation set compares models, tunes hyperparameters, and chooses thresholds. The test set is opened once at the end to estimate performance on untouched data. Repeatedly consulting the test result turns it into another validation result and makes the final estimate optimistic.

A common workflow

split cases into training, validation, and final test sets
fit preprocessing using training data only
for each candidate model and hyperparameter setting:
    fit parameters on training data
    score on validation data
choose the setting that meets the real decision objective
refit according to the agreed protocol
evaluate once on the untouched test set
deploy, monitor drift, and revalidate when the data changes

4.1 Supervised learning — the workhorses

Linear regression — fit a numerical response

Purpose. Linear regression estimates how a numerical target changes with its features and provides a transparent baseline. It predicts \(\hat y_i=w^\top x_i+b\). The residual \(r_i=\hat y_i-y_i\) is the signed prediction error: positive means the model predicted too high. Squaring residuals makes large misses expensive and produces a smooth objective.

With mean squared error written as \(J(w,b)=\frac{1}{2n}\sum_{i=1}^{n}(w^\top x_i+b-y_i)^2\), the gradients are \(\nabla_wJ=\frac1nX^\top(Xw+b\mathbf1-y)\) and \(\partial J/\partial b=\frac1n\sum_i r_i\). Gradient descent repeatedly moves against these slopes. If \(\widetilde X=[\mathbf1\;X]\) includes the intercept column, a least-squares solution satisfies the normal equations \(\widetilde X^\top\widetilde X\,\theta=\widetilde X^\top y\), where \(\theta=(b,w^\top)^\top\).

Numerical stability

The formula \((\widetilde X^\top\widetilde X)^{-1}\widetilde X^\top y\) describes a solution when the inverse exists, but production code should not form that inverse explicitly. Solve the system with QR, SVD, or a suitable linear solver; SVD also gives a minimum-norm solution when features are collinear. Standardize features before gradient descent when their scales differ.

Worked calculation

For points \((x,y)=(0,1),(1,3),(2,5)\), the line \(\hat y=2x+1\) has residuals \((0,0,0)\), hence MSE \(0\). Starting instead at \(w=b=0\), the residuals are \((-1,-3,-5)\), so \(\partial J/\partial w=-13/3\) and \(\partial J/\partial b=-3\). A learning-rate \(0.1\) step gives \(w=0.433\), \(b=0.300\): one move toward the fitted line, not the final answer. 

initialize w and b
repeat until the validation score stops improving:
    predictions = X w + b
    residuals = predictions - y
    gradient_w = X^T residuals / number_of_samples
    gradient_b = mean(residuals)
    w = w - learning_rate * gradient_w
    b = b - learning_rate * gradient_b

Assumptions and use. The model assumes an additive linear mean response. Gaussian, constant-variance, independent residual assumptions matter for classical confidence intervals, not for merely computing predictions. Inspect residual plots for curvature, unequal spread, groups, and outliers. Use linear regression when interpretability and a defensible baseline matter, or when the relationship is plausibly linear after sensible transformations.

Logistic regression — turn a score into a class probability

Purpose and intuition. A linear score can range over all real numbers, whereas a probability must stay between \(0\) and \(1\). Logistic regression models the log-odds as a line, \(\log\frac{p_i}{1-p_i}=w^\top x_i+b\), then applies the sigmoid \(p_i=\sigma(z_i)=1/(1+e^{-z_i})\). A one-unit increase in feature \(j\), holding the others fixed, multiplies the odds by \(e^{w_j}\).

For binary labels, minimize cross-entropy \(J(w,b)=-\frac1n\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]\). Its weight gradient is \(\nabla_wJ=\frac1nX^\top(p-y)\), the same "prediction minus observation" pattern as linear regression. The fitted probability is converted to an action by a chosen threshold; \(0.5\) is a convention, not a law.

Worked calculation

If the fitted score for a sample is \(z=1.2\), then \(p=1/(1+e^{-1.2})\approx0.768\). A threshold of \(0.5\) predicts the positive class; a threshold of \(0.8\) does not. The score and probability did not change—the decision policy did. 

initialize w and b
repeat:
    scores = X w + b
    probabilities = sigmoid(scores)
    w = w - learning_rate * X^T(probabilities - y) / n
    b = b - learning_rate * mean(probabilities - y)
choose a threshold using validation data and decision costs

With ordinary full-rank data and a finite optimum, the logistic loss is convex, so optimization does not have competing local minima. Perfectly separable unregularized data can drive coefficient norms toward infinity rather than yield a finite optimum. Probabilities are often reasonably calibrated when the log-odds model is appropriate, but calibration is empirical: check a reliability plot and recalibrate on held-out data when probability quality matters.

L1 and L2 regularization — trade a little fit for stability

Flexible models can chase noise or assign huge, unstable coefficients to correlated features. Regularization adds a cost for coefficient size. For a data loss \(L(w,b)\), ridge uses \(J_{L2}=L+\frac{\lambda}{2}\|w\|_2^2\), while lasso uses \(J_{L1}=L+\lambda\|w\|_1\). The intercept is normally left unpenalized. Because a penalty acts on numerical coefficient size, standardize continuous features inside each training fold before comparing their penalties.

Decision trees — learn questions one split at a time

A classification tree partitions the feature space with rules such as "temperature ≤ 18". At a node containing class proportions \(p_k\), Gini impurity is \(G=1-\sum_kp_k^2\), and entropy is \(H=-\sum_kp_k\log_2p_k\), with \(0\log0=0\). For left and right children, the split improvement is \(\Delta I=I(\text{parent})-\frac{n_L}{n}I(L)-\frac{n_R}{n}I(R)\). The weights matter: a tiny pure child should not outweigh a large mixed child.

Worked split

Suppose the left child contains \(4\) positives and \(0\) negatives, while the right contains \(2\) positives and \(4\) negatives. The parent has \(6/10\) positives, so its Gini impurity is \(0.48\). The weighted children have impurity \((4/10)(0)+(6/10)[1-(2/6)^2-(4/6)^2]=0.267\). The gain is therefore \(0.213\).

Trees do not require feature scaling and naturally express interactions, but ordinary axis-aligned trees can be unstable: a small data change may produce a different sequence of splits.

If individual estimators have variance \(\sigma^2\) and pairwise correlation ρ, the average of \(B\) has variance \(\rho\sigma^2+(1-\rho)\sigma^2/B\). Variance falls nearly as \(1/B\) only when errors are nearly uncorrelated; a shared correlated component remains. Boosting often reduces bias and variance together in practice, so "bagging equals variance, boosting equals bias" is a useful first intuition, not a universal accounting identity.

Support vector machines — maximize a robust separating margin

With labels \(y_i\in\{-1,+1\}\), a linear soft-margin SVM minimizes \(\frac12\|w\|^2+C\sum_i\max(0,1-y_i(w^\top x_i+b))\). The hinge-loss term penalizes points on the wrong side or inside the unit margin; \(C\) controls how strongly violations are penalized. Large \(C\) prioritizes training fit and can narrow the margin, while small \(C\) accepts more violations for stronger regularization.

In the dual formulation, examples interact through inner products. Replacing \(x_i^\top x_j\) with a valid kernel \(k(x_i,x_j)=\langle\phi(x_i),\phi(x_j)\rangle\) gives a nonlinear boundary without explicitly constructing φ. For the RBF kernel \(e^{-\gamma\|x-x'\|^2}\), large γ makes similarity very local and can create a wiggly boundary; small γ makes it smoother. Scale features before distance-based kernels. Points with nonzero dual coefficients are support vectors; with soft margins, these include points on or inside the margin, not only points lying exactly on two geometric lines.

k-nearest neighbors — predict from local examples

k-NN stores the training data. At inference, compute a distance from a query to each stored point, select the \(k\) nearest, then use a majority or distance-weighted vote for classification (or a mean for regression). Small \(k\) follows local detail but is sensitive to noise; large \(k\) smooths the decision and can erase minority regions. Choose \(k\), the distance, and any weighting on validation data.

Distances are meaningless when one feature's units dominate, so scale features and treat categorical variables deliberately. A direct query costs roughly \(O(nd)\), although spatial indexes can help in favorable low dimensions. As dimension grows, data becomes sparse and neighbor distances can become less distinguishable—the curse of dimensionality. There is no universal dimensional cutoff: sample size, metric, noise, sparsity, and intrinsic dimension all matter.

⚛ Physics bridge

Linear regression is least-squares parameter estimation; ridge is Tikhonov regularization. An SVM margin resembles finding the widest energy-free corridor between two populations, while a kernel is a Gram matrix of pairwise overlaps. In each case, the algorithm is easier to understand when you ask what objective is minimized and what geometry the objective prefers.

4.2 Unsupervised learning — structure without labels

Unsupervised methods do not discover a single hidden truth automatically. They impose a definition of structure—compact groups, dense regions, Gaussian components, or high-variance directions—and expose the pattern favored by that definition. Always connect a cluster or component back to domain variables before giving it a substantive name.

k-means — compact groups around representative centers

Purpose and objective. Given a requested number of clusters \(k\), k-means finds assignments \(c_i\in\{1,\ldots,k\}\) and centroids \(\mu\) that minimize the within-cluster sum of squares, also called inertia: $$J(c,\mu)=\sum_{i=1}^{n}\|x_i-\mu_{c_i}\|_2^2.$$ It alternates the two steps of Lloyd's algorithm because optimizing assignments with fixed centroids and optimizing centroids with fixed assignments are both easy. 

choose k initial centroids
repeat:
    assignment step:
        assign every sample to its nearest centroid
    update step:
        replace each centroid by the mean of its assigned samples
        if a cluster is empty, apply a declared recovery rule
until assignments stop changing or improvement is below tolerance
repeat from several seeds; keep the run with lowest inertia

Each exact assignment or mean-update step cannot increase inertia. With deterministic tie handling, the finite set of assignments leads to a fixed point; numerical implementations usually stop at a tolerance or iteration limit. This is convergence of the procedure, not a guarantee of the globally best clustering. k-means++ spreads initial centers to improve the starting solution, and multiple restarts reduce sensitivity further.

Scaling and failure modes

Squared Euclidean distance lets large-unit features dominate, so standardize or otherwise choose scales that express domain importance. Means are sensitive to outliers. k-means favors compact, roughly spherical, similar-density groups and may cut an elongated band into pieces. Empty clusters can occur after assignment; an implementation must keep the old center, reseed it, or move it to a high-error point rather than silently divide by zero.

Choose \(k\) with a mix of domain usefulness and validation: inspect an elbow in inertia, silhouette scores, stability across resamples, and whether the resulting groups support the downstream task. None of these rules makes \(k\) an objective fact about the world.

Hierarchical clustering — a tree of possible groupings

Agglomerative hierarchical clustering begins with one cluster per sample and repeatedly merges the nearest pair. A dendrogram records which clusters merged and at what dissimilarity; cutting it at a chosen height produces a flat clustering. You can inspect several resolutions without rerunning the algorithm, but you still choose a distance, a linkage, and eventually a cut.

LinkageDistance between two clustersTypical behavior
SingleClosest pair of pointsCan recover chains; vulnerable to bridges
CompleteFarthest pair of pointsPrefers compact groups; sensitive to extremes

WardIncrease in within-cluster squared errorCompact variance-minimizing groups with Euclidean geometry

Use hierarchical clustering when the hierarchy itself is meaningful or when the dataset is small enough to inspect a dendrogram. Scale features first when their units are not comparable. Early greedy merges are not revisited, and a dendrogram's vertical scale is linkage dissimilarity—not a probability that two groups are genuinely distinct. Storing pairwise distances typically requires \(O(n^2)\) memory, and runtime is often at least quadratic depending on linkage and implementation, so full dendrogram methods do not scale like k-means.

DBSCAN — clusters as connected dense regions

DBSCAN uses a radius ε and a neighborhood count min_samples. A core point has at least that many samples in its ε-neighborhood (conventions normally count the point itself). A border point is reachable from a core point but is not itself core. A point not density-reachable from any core is labeled noise. Connected core neighborhoods form clusters, allowing curved shapes and no predeclared number of clusters.

How to reason about the two controls

Increasing ε connects more points and tends to merge groups or absorb noise. Increasing min_samples demands stronger local evidence and tends to create more noise. Inspect a sorted nearest-neighbor-distance plot as a diagnostic, then test stability. One global ε often fails when densities vary, and distance concentration creates trouble in high dimensions.

Gaussian mixtures and EM — soft membership in overlapping groups

A Gaussian mixture models a density \(p(x)=\sum_{j=1}^{k}\pi_j\,\mathcal N(x\mid\mu_j,\Sigma_j)\), where mixture weights π are nonnegative and sum to one. Rather than assign a point completely to one group, it computes a responsibility $$r_{ij}=P(z_i=j\mid x_i)= \frac{\pi_j\mathcal N(x_i\mid\mu_j,\Sigma_j)} {\sum_\ell\pi_\ell\mathcal N(x_i\mid\mu_\ell,\Sigma_\ell)}.$$ 

initialize mixture weights, means, and covariances
repeat:
    E-step: compute every responsibility r[i,j]
    M-step:
        N[j] = sum_i r[i,j]
        weight[j] = N[j] / n
        mean[j] = sum_i r[i,j] * x[i] / N[j]
        covariance[j] = responsibility-weighted residual covariance
until log-likelihood improvement is below tolerance
run several initializations and compare held-out likelihood or a model criterion

Each exact EM iteration does not decrease the observed-data likelihood, but it may finish at a local maximum or saddle point. A component can collapse around too few samples and make a covariance nearly singular; covariance regularization, minimum component sizes, and multiple starts are common safeguards. Spherical, diagonal, tied, and full covariance choices trade flexibility against data and computation. Use a GMM when elliptical overlap and soft membership are meaningful, not merely because the scatterplot looks clustered.

PCA — compress along the directions of greatest variance

Start by centering each feature: \(X_c=X-\mathbf1\mu^\top\). Standardize as well when feature units are arbitrary and variance should not imply importance; do not standardize automatically when physical variance in common units is the signal. If \(S=X_c^\top X_c/(n-1)=V\Lambda V^\top\), the columns of \(V\) are orthonormal principal directions and eigenvalues λ give variance along them. Equivalently, obtain the same directions from the SVD of \(X_c\).

Keeping \(r\) components gives scores \(Z=X_cV_r\) and the reconstruction \(\widehat X=ZV_r^\top+\mathbf1\mu^\top\). The entries of \(V_r\) are loadings: they show how original features contribute to each direction. The explained-variance ratio of component \(j\) is \(\lambda_j/\sum_\ell\lambda_\ell\), and the retained fraction is the sum over kept components. Eigenvector signs are arbitrary: flipping a loading vector and its scores changes no geometry.

Worked calculation

If the covariance eigenvalues are \(5,2,1\), total variance is \(8\). The first component explains \(5/8=62.5\%\); the first two explain \((5+2)/8=87.5\%\). PCA would therefore retain \(87.5\%\) with two components and discard \(12.5\%\) of the measured variance.

⚛ Physics bridge

EM is a self-consistency loop: infer latent responsibilities from parameters, then infer parameters from responsibilities—the same alternating structure seen in mean-field iterations. PCA is normal-mode analysis of a covariance matrix: diagonalize it, retain the largest-eigenvalue directions, and quantify the discarded fluctuation through the omitted eigenvalues.

4.3 Model evaluation — where careers are made and lost

Design the evaluation before fitting the model

Evaluation estimates performance on the population and decision process that will actually be encountered. Split by the unit that must generalize independently, not automatically by row. A random row split is sound only when rows are sufficiently independent and identically distributed.

Data situationSplit strategyWhat it prevents
Independent cases with unequal class sharesStratified split or stratified foldsAccidental folds with very different prevalence
Many rows per patient, device, user, or siteGrouped split; keep each entity in one sideRecognizing the same entity instead of generalizing

In \(K\)-fold cross-validation, train on \(K-1\) folds and validate on the remaining fold, rotate the held-out fold, and summarize both the mean and spread. Hyperparameter comparison happens through these validation results; an untouched test set still supplies the final estimate. If model choice itself must be evaluated with very limited data, nested cross-validation separates the inner tuning loop from the outer performance estimate.

The confusion matrix — count the four possible outcomes

For a chosen positive class and threshold, predictions fall into true positives (TP), false positives (FP), false negatives (FN), and true negatives (TN). From these counts: $$\text{accuracy}=\frac{TP+TN}{N},\quad \text{precision}=\frac{TP}{TP+FP},\quad \text{recall}=\frac{TP}{TP+FN},$$ $$\text{specificity}=\frac{TN}{TN+FP},\quad \text{FPR}=\frac{FP}{FP+TN},\quad F_1=\frac{2\,\text{precision}\,\text{recall}} {\text{precision}+\text{recall}}.$$ Accuracy is informative when class frequencies and error costs make it appropriate; it is misleading when a large majority class hides poor minority performance.

Worked rare-event example

With TP=60, FP=140, FN=40, and TN=9,760, there are 100 positives among 10,000 cases. Accuracy is \(9,820/10,000=98.2\%\), precision is \(60/200=30\%\), recall is \(60/100=60\%\), specificity is \(9,760/9,900\approx98.6\%\), FPR is \(140/9,900\approx1.4\%\), and F1 is \(40\%\). High accuracy coexists with about \(2.3\) false alerts for every true alert.

Thresholds, ranking, and calibration answer different questions

QuestionUseful measuresDepends on one threshold?
How good are today's actions?Precision, recall, specificity, F1, expected costYes
How well are positives ranked above negatives?ROC-AUC, precision-recall curve, AP / PR-AUCNo; they sweep thresholds

The ROC curve plots TPR against FPR as the threshold moves. ROC-AUC equals the probability that a randomly selected positive receives a higher score than a randomly selected negative, with half credit for ties. It measures discrimination and, for fixed class-conditional score distributions, does not change merely because prevalence changes. That prevalence invariance can make ROC-AUC less aligned with rare-event workload—not mathematically "inflated," but incomplete for that decision.

A precision-recall curve plots precision against recall. Its no-skill precision baseline is the positive prevalence, so it directly exposes alert quality under imbalance and changes when prevalence changes. Average precision (AP) and trapezoidal PR-AUC are different summaries and need not be numerically identical; report which convention is used. Thresholds should be chosen from validation data using costs or operational constraints, then checked for calibration and subgroup behavior.

Regression metrics — define what a costly miss means

Three common summaries

MAE \(=n^{-1}\sum_i|y_i-\hat y_i|\) measures a typical absolute miss in target units and is less dominated by extremes. RMSE \(=\sqrt{n^{-1}\sum_i(y_i-\hat y_i)^2}\) is also in target units but gives large errors more influence. R² \(=1-\sum_i(y_i-\hat y_i)^2/\sum_i(y_i-\bar y)^2\) compares squared error with predicting the evaluation-set mean; it can be negative on new data. Report a metric whose penalty matches the application, often alongside residual plots and a simple baseline.

Learning curves are not validation curves

A learning curve plots training and validation performance against the amount of training data. If both errors plateau high and close, the model is underfitting; more data alone may not repair insufficient features or capacity. If training error is low and validation error is materially worse, more representative data or stronger regularization may reduce variance.

A validation curve plots training and validation performance against one model setting such as polynomial degree, tree depth, \(C\), or \(\lambda\). It diagnoses which capacity setting generalizes best. The chart below varies degree, so it is a validation curve. In either chart, interpret uncertainty across folds or resamples rather than overreading a single jagged point.

Degree 12+ overfits (high variance): press "new noise sample" repeatedly and watch the high-degree fit thrash while degree 4 barely moves — variance is sensitivity to the training draw. Choose degree near the validation-error minimum, then reserve the untouched final test set for the one-time performance estimate.

Class imbalance — change training and decisions without falsifying evaluation

Imbalance matters because a scarce positive class may receive too little influence during fitting and because operational precision depends strongly on prevalence. Keep validation and test sets at the deployment distribution unless the evaluation question explicitly specifies another population. Apply any data-level balancing to training partitions only.

Oversampling or weighting can change the relationship between raw scores and real-world event probabilities. When probabilities matter, assess and if necessary recalibrate on held-out data with natural prevalence. Report the metric family that answers the decision: PR curves are often useful for rare alerts, ROC curves describe ranking across both classes, and threshold metrics or expected cost describe the deployed action.

Data leakage — protect the direction of information flow

Leakage occurs when model development uses information that would not be available for a genuinely new prediction. It can enter through features, preprocessing, splitting, or repeated model selection. An implausibly strong validation score is a clue, but plausible scores do not prove the pipeline safe.

Leakage routeExampleSafe design
PreprocessingScale or impute using all rows before splittingFit each transformation on fold-training only

A pipeline helps, but cannot decide causality

Software pipelines can enforce fold-local fitting, yet they cannot know that a feature arrives after the event, that two identifiers belong to one person, or that the deployment population has shifted. Preventing leakage also requires a data-lineage and time-of-availability review with domain experts.

Self-check

Ten cumulative questions connect the equations, algorithms, and evaluation choices.

1. What is the safest way to compute an ordinary least-squares fit when the design matrix includes an intercept?

c. The normal equations characterize a solution, but an explicit inverse is unnecessary and can magnify conditioning problems. QR or SVD solves least squares more reliably; SVD also handles rank deficiency.

2. A logistic model gives score \(z=1.2\), hence \(p\approx0.768\). What happens when the action threshold is \(0.8\)?

b. A threshold converts an unchanged score or probability into an action. Threshold selection is separate from fitting and should reflect validation evidence, costs, and constraints.

3. For \(a=3,\lambda=1\), compare \(\tfrac12(w-a)^2+\lambda|w|\) with \(\tfrac12(w-a)^2+\tfrac\lambda2w^2\).

d. L1 soft-thresholds to \(3-1=2\); L2 shrinks smoothly to \(3/(1+1)=1.5\). L1 can create exact zeros when \(|a|\le\lambda\), but it does not guarantee an arbitrary requested feature count.

4. Which statement about trees and their ensembles is technically sound?

a. Correlation leaves a variance floor for bagging, and boosting can affect both bias and variance. Training-impurity improvement does not guarantee validation improvement.

5. Which preprocessing choice is most important for both RBF-SVM and ordinary Euclidean k-NN?

c. Both methods depend on distances, so a large-unit feature can dominate. Dimensional difficulty has no universal cutoff; it depends on sample size, metric, noise, and intrinsic geometry.

6. Which description of unsupervised methods is correct?

d. Each method defines structure differently. Lloyd steps do not increase inertia but can settle locally; EM likewise improves likelihood monotonically without guaranteeing its global maximum.

7. PCA covariance eigenvalues are \(5,2,1\). What do two retained components explain, and what can a later t-SNE plot prove?

b. Retained variance is \((5+2)/(5+2+1)=87.5\%\). Nonlinear maps emphasize neighborhoods and can change substantially with settings and seeds; apparent area and separation are not direct measurements.

8. For TP=60, FP=140, FN=40, TN=9,760, which metric set is correct?

a. The denominator for precision is predicted positives (200); for recall it is actual positives (100). The high accuracy reflects the many true negatives and does not summarize alert quality.

9. Prevalence falls while the positive and negative score distributions stay unchanged. Which statement is correct?

c. ROC-AUC depends on relative ranking between the conditional score distributions, whereas precision contains prevalence through the mix of positive and negative predictions. A threshold selects one operating point but does not change either full-curve area.

10. Which end-to-end evaluation procedure is sound?

d. Degree produces a validation curve; training-set size produces a learning curve. Fold-local transformations, train-only resampling, entity/time-aware splits, and one-time final testing protect the estimate from leakage and adaptive overfitting.
