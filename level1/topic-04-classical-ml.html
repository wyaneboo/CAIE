Classical Machine Learning

Before transformers there were twenty years of algorithms that still win on tabular data, still run half the world's fraud detection and credit scoring, and still supply the vocabulary — overfitting, regularization, evaluation — that every deep-learning conversation is conducted in. A senior engineer who reaches for a neural net on 5,000 rows of tabular data has failed this topic.

Learning outcomes
  • Derive and implement linear and logistic regression; explain L1/L2 regularization and contrast their effects on weights.
  • Describe decision trees (Gini/entropy splits); explain bagging, random forests, and boosting; describe SVMs, the kernel trick, and margin maximization; apply k-NN and explain the curse of dimensionality.
  • Implement k-means and explain its convergence and failure modes; describe hierarchical clustering, DBSCAN, GMMs and EM; apply PCA; explain t-SNE/UMAP and their distortions.
  • Calculate accuracy, precision, recall, F1, ROC-AUC, PR-AUC and choose among them; diagnose over/underfitting from learning curves; describe class-imbalance strategies; explain data leakage.

4.1 Supervised learning — the workhorses

Linear regression models \(y = w^\top x + b\) and minimizes squared error. Setting the gradient to zero gives the closed-form normal equations \(w = (X^\top X)^{-1} X^\top y\) — one of the few ML problems with an exact solution (and an MLE under Gaussian noise, connecting to Topic 2). Logistic regression pushes the linear score through a sigmoid, \(p = \sigma(w^\top x) = 1/(1+e^{-w^\top x})\), and maximizes likelihood — equivalently minimizes cross-entropy. No closed form, but the loss is convex, so gradient descent finds the global optimum. Despite the name it is a classifier, and it remains the default first model for any binary problem: fast, calibrated, interpretable.

Regularization adds a penalty on weight size: L2 (ridge) adds \(\lambda\|w\|_2^2\) and shrinks all weights smoothly toward zero; L1 (lasso) adds \(\lambda\|w\|_1\) and drives many weights exactly to zero, performing feature selection. Geometric reason: the L1 ball has corners on the axes, and optima land on corners. In MAP terms (Topic 2): Gaussian vs Laplace priors.

Decision trees recursively split the feature space with axis-aligned thresholds, choosing at each node the split that most purifies the classes — maximum reduction in Gini impurity \(\sum_k p_k(1-p_k)\) or in entropy \(-\sum_k p_k \log p_k\>\) (information gain). Trees are interpretable and handle mixed feature types, but a deep tree memorizes noise — high variance. The fixes are ensembles:

  • Bagging: train many trees on bootstrap resamples and average. Averaging \(B\) weakly-correlated estimators divides variance by nearly \(B\) — pure Topic 2 statistics. Random forests add feature subsampling per split to decorrelate the trees further.
  • Boosting is sequential instead of parallel: each new small tree is fit to the errors of the ensemble so far. AdaBoost reweights misclassified points; gradient boosting generalizes this — each tree fits the negative gradient of the loss (for squared error, literally the residuals). XGBoost/LightGBM are engineered implementations with regularization and second-order steps; they remain the strongest default on tabular data, and knowing that is exam material.

SVMs choose the separating hyperplane that maximizes the margin — the distance to the nearest points (the support vectors). The optimization only ever touches data through inner products \(\langle x_i, x_j \rangle\), so you can swap in a kernel \(k(x_i, x_j) = \langle \phi(x_i), \phi(x_j)\rangle\) and implicitly work in a huge (even infinite-dimensional, for RBF) feature space without computing \(\phi\) — the kernel trick. That "Gram matrix of pairwise similarities" pattern is the same algebra you'll meet again as attention scores in Topic 8.

k-NN classifies by voting among the k nearest training points — no training at all, all cost at query time. It exposes the curse of dimensionality: in high dimensions, volume concentrates in shells; the ratio between nearest and farthest neighbor distances → 1, and "nearest" stops meaning anything. Rule of thumb: distance-based methods degrade badly beyond a few dozen raw dimensions unless the data lies on a low-dimensional manifold — which, fortunately, real data usually does (that's why embeddings in Topic 14 work at 768-d: the intrinsic dimension is far lower).

4.2 Unsupervised learning — structure without labels

k-means alternates two steps: assign each point to its nearest centroid; move each centroid to the mean of its points. Each step can only decrease the total within-cluster squared distance (the "inertia"), and there are finitely many assignments, so it always converges — but only to a local optimum that depends on initialization (hence k-means++ seeding and multiple restarts). Failure modes: you must pick k; it assumes round, similar-size clusters (it's secretly a hard-assignment Gaussian mixture with equal spherical covariances); it shreds elongated or nested shapes.

The relatives. Hierarchical clustering greedily merges nearest clusters, producing a dendrogram — no k needed until you cut it. DBSCAN defines clusters as dense regions (points with ≥ minPts neighbors within ε), discovers the number of clusters itself, finds arbitrary shapes, and labels sparse points as noise — but struggles when densities vary. Gaussian Mixture Models replace hard assignments with soft ones and fit with the EM algorithm: E-step computes responsibilities \(P(\text{cluster}\mid x)\) (a Bayes-rule step), M-step re-fits each Gaussian's weight, mean, covariance from its responsibility-weighted points. EM monotonically increases likelihood; k-means is its zero-covariance limit.

⚛ Physics bridge

EM is a mean-field self-consistency loop: responsibilities given parameters, parameters given responsibilities, iterate to a fixed point — the same structure as Hartree–Fock or solving for a mean field magnetization. And PCA you already know cold: diagonalize the covariance matrix, keep the largest-eigenvalue modes. "Fraction of variance retained" is the ratio of kept eigenvalues to the trace — exactly how you'd truncate a normal-mode expansion.

PCA projects data onto the top eigenvectors of its covariance (equivalently, the top right-singular vectors of the centered data matrix — Topic 1's SVD). It is linear, fast, deterministic, and the right first move for compression and decorrelation. t-SNE and UMAP are nonlinear visualization maps: they try to preserve local neighborhoods when squashing to 2-D. Both distort: cluster sizes and inter-cluster distances in a t-SNE plot are essentially meaningless, and perplexity / n_neighbors settings can manufacture or merge clusters. Use them to explore, never to measure.

4.3 Model evaluation — where careers are made and lost

For binary classification, everything flows from the confusion matrix: true/false positives and negatives. Precision = TP/(TP+FP): of the things I flagged, how many were real? Recall = TP/(TP+FN): of the real things, how many did I catch? F1 is their harmonic mean. Accuracy is the fraction correct — and is worthless under class imbalance: a fraud model that says "never fraud" is 99.8% accurate. The ROC curve traces (false-positive rate, true-positive rate) as the decision threshold sweeps; its area, ROC-AUC, is the probability a random positive scores above a random negative. Under heavy imbalance even ROC-AUC flatters (FPR's denominator is the huge negative class), so precision-recall curves and PR-AUC are the honest view for rare-event problems. Choosing the metric is the engineering decision; the threshold that trades precision against recall is a business decision — that framing returns in Topics 7 and 13.

Things to try: (1) drop positives to 1% and watch accuracy stay high while precision collapses — the imbalance trap. (2) Note AUC doesn't move when you drag the threshold: AUC is a property of the scorer, the threshold picks your operating point on it. (3) Push separation to 3 — this is what "a better model" means: the whole tradeoff curve improves.

Overfitting vs underfitting is diagnosed from learning curves: training and validation error vs model capacity (or data size). Underfit: both errors high and close — add capacity or features. Overfit: training error low, validation error high and rising with capacity — regularize, simplify, or get data. The widget below makes the whole story one slider.

Interactive — bias–variance with one slider
Polynomial regression on 30 noisy samples of a smooth function. Left: the fit; right: train vs test error as degree grows — the canonical U-curve.

Degree 0–1 underfits (high bias): the model can't bend. Degree 12+ overfits (high variance): press "new noise sample" repeatedly and watch the high-degree fit thrash while degree 4 barely moves — variance is literally sensitivity to the training draw. The test-error minimum sits at moderate capacity. Every regularizer in this course is a way of buying that sweet spot.

Class imbalance strategies: resample (oversample minority — e.g. SMOTE — or undersample majority), reweight the loss (class weights inversely proportional to frequency), or use focal loss, which down-weights already-easy examples so training focuses on the hard minority. And always report PR-AUC, not accuracy.

Data leakage is the silent career-ender: information from outside the training window contaminating training. Canonical forms: normalizing with statistics computed on the full dataset before splitting; features that encode the label (e.g., "charged-off fees" when predicting default); random splits of time-series (the model peeks at the future); duplicate or near-duplicate rows straddling the split. Symptom: validation metrics too good to be true, then a production faceplant. Rule: fit every preprocessing step inside the training fold only — pipelines exist to enforce this.

Jargon decoder
hyperparameter
A knob you set (k, depth, λ, learning rate), not learned from data. Tuned on a validation set, never the test set.
bootstrap
Resampling the dataset with replacement; "bagging" = bootstrap aggregating.
support vector
A training point lying on the margin — one of the few points that actually determine the SVM boundary.
RBF kernel
Radial basis function \(e^{-\gamma\|x-x'\|^2}\) — similarity decaying with distance; implicitly infinite-dimensional features.
SMOTE
Synthetic Minority Oversampling — creates synthetic minority points by interpolating between neighbors.
inertia
k-means objective: total squared distance of points to their assigned centroid.
dendrogram
The merge tree produced by hierarchical clustering.
calibration
Whether predicted probabilities match observed frequencies (of events given p=0.8, ~80% happen). Logistic regression is naturally well-calibrated; boosted trees and deep nets often aren't.

Self-check

1. You need a model that uses at most 20 of 5,000 candidate features, for regulatory interpretability. The most direct tool:

b. L1's corners produce exact zeros — built-in feature selection. L2 shrinks everything but zeroes nothing.

2. Random forests reduce error primarily by reducing ______; gradient boosting primarily by reducing ______.

c. Bagging averages many overfit (low-bias, high-variance) trees — averaging kills variance. Boosting adds weak (high-bias) learners that sequentially correct systematic errors — reducing bias. This duality is a favorite exam item-set.

3. Fraud is 0.2% of transactions. Which evaluation setup is sound?

d. Test distributions must match reality (rebalancing the test set falsifies precision). Accuracy saturates at 99.8% for a useless model; ROC-AUC is inflated by the enormous negative class. PR-AUC + an explicit operating point is the professional answer.

4. A colleague scales all features using the full dataset's mean/std, then splits train/test, and reports great results. The problem:

a. Even label-free statistics leak distributional information across the split (means, spread, outlier locations). Usually a small crime — but the same habit with target encoding or time-series is catastrophic. Pipelines make the discipline automatic.
