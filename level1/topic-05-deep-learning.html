Deep Learning Fundamentals

Deep learning builds trainable functions by composing simple layers. A forward pass turns an input into a prediction; a loss measures the error; backpropagation uses the chain rule to assign each weight its share of that error. The central mathematics is compact, but reliable learning depends on activation choice, initialization, normalization, regularization, optimization, and an architecture that respects the structure of the data. This chapter develops those choices as one connected workflow rather than a list of names.

Learning outcomes
  • Describe the perceptron, MLP, and universal approximation theorem; derive backpropagation for a multi-layer network.
  • Compare activation functions (sigmoid, tanh, ReLU, GELU, SwiGLU) and their gradient behavior; explain Xavier/He initialization.
  • Describe batch/layer/RMS normalization; explain dropout, weight decay, early stopping; describe warmup and cosine-decay schedules.
  • Diagnose training instabilities (NaN losses, dead neurons, exploding gradients).
  • Describe CNNs (convolution, pooling, receptive fields, parameter sharing), RNNs/LSTMs/GRUs and the vanishing-gradient problem, attention at a foundational level, and autoencoders.

Orientation — the objects that move through a neural network

A sample is one case, such as one image, waveform, sentence, or experimental run. A feature is one measured input. A tensor is a rectangular array that carries numbers through the model: a vector is an order-1 tensor, a matrix is order 2, and a batch of colour images might have shape \(B\times H\times W\times C\). A batch is the group of samples used to estimate one update. Always read a tensor by asking what each axis represents; compatible dimensions are a mathematical requirement, not merely a programming detail.

Training, validation, and test have different jobs

The training set supplies gradients and fits weights. The validation set selects architectures, regularization, stopping time, and other hyperparameters. The test set is kept untouched until the end for one final estimate. Preprocessing statistics, augmentation choices, and early-stopping decisions must not learn from the test set. A low training loss says the optimizer fit known data; it does not by itself demonstrate generalization.

5.1 From perceptron to universal approximator

Purpose and intuition — learn a useful representation, then a prediction

A single perceptron first forms the affine score \(z=w^\top x+b\), then applies an activation \(h=\phi(z)\). Without the activation, composing layers would still be only one affine transformation. With nonlinear activations, later layers can reuse simpler patterns learned by earlier layers. A single thresholded perceptron separates space with one hyperplane, so it cannot represent XOR; a hidden layer can combine several half-spaces to create a non-linear decision region.

From one unit to a multi-layer perceptron

Let \(h^{(0)}=x\). A dense multi-layer perceptron (MLP) applies $$z^{(l)}=W^{(l)}h^{(l-1)}+b^{(l)},\qquad h^{(l)}=\phi^{(l)}(z^{(l)}).$$ Row \(j\) of \(W^{(l)}\) contains the incoming weights for unit \(j\). If a batch has \(B\) samples, implementations often store samples as rows and perform the equivalent batched matrix operation. The last layer produces one regression value or a vector of class logits. For \(K\) mutually exclusive classes, softmax converts logits to \(p_k=e^{z_k}/\sum_j e^{z_j}\); subtract the largest logit first when calculating it to avoid overflow.

Worked forward calculation

Take one input \(x=2\), one ReLU hidden unit, and a sigmoid output. With \(w_1=0.5,b_1=0.1,w_2=1.2,b_2=-0.3\), the hidden pre-activation is \(z_1=0.5(2)+0.1=1.1\), so \(h=\max(0,1.1)=1.1\). The output logit is \(z_2=1.2(1.1)-0.3=1.02\), hence \(p=\sigma(1.02)\approx0.735\). For target \(y=1\), binary cross-entropy is \(-\log p\approx0.308\). Each number has a distinct role: activation \(h\), logit \(z_2\), probability \(p\), and scalar loss \(L\).

Universal approximation — powerful, but not a training guarantee

A common universal approximation result assumes a continuous, non-polynomial activation (the exact assumptions vary by theorem) and says that a sufficiently wide one-hidden-layer network can approximate any continuous function on a compact domain as closely as desired. This is an existence statement. It does not give a practical width, say that gradient-based training will find the required weights, remove the need for data, or guarantee performance outside the observed domain. Depth is valuable because many real relationships are compositions: a deep model can reuse intermediate features and may express some structured functions far more efficiently than a shallow model. “Universal” therefore does not mean “automatically suitable.”

Backpropagation — reuse the chain rule from output to input

Backpropagation is not a separate learning rule; it is an efficient bookkeeping procedure for derivatives. For the following single-example column-vector notation with elementwise hidden activations, define the error signal at layer \(l\) as \(\delta^{(l)}=\partial L/\partial z^{(l)}\). Starting at the output and moving backward gives $$\delta^{(L)}=\nabla_{h^{(L)}}L\odot\phi^{(L)\prime}(z^{(L)}),$$ $$\delta^{(l)}=\left(W^{(l+1)\top}\delta^{(l+1)}\right) \odot\phi^{(l)\prime}(z^{(l)}),$$ $$\frac{\partial L}{\partial W^{(l)}}=\delta^{(l)}h^{(l-1)\top},\qquad \frac{\partial L}{\partial b^{(l)}}=\delta^{(l)}.$$ The transpose redistributes downstream sensitivity to the units that fed it. The outer product then pairs each unit’s input activation with its output error. Reverse-mode differentiation stores or recomputes forward intermediates, so its arithmetic cost is usually a small multiple of the forward pass—not one full pass per parameter. Cached activations consume memory; checkpointing trades extra recomputation for lower memory. For a minibatch, implementations carry a batch axis and sum or average the per-example outer products according to the loss convention. The Hadamard-product output formula assumes an elementwise output activation. Softmax is coupled across classes, so its general backward step is a Jacobian–vector product; paired with cross-entropy, that product simplifies to \(\delta^{(L)}=p-y\).

Worked backward calculation

Continue the example above. Sigmoid plus binary cross-entropy gives \(\partial L/\partial z_2=p-y\approx-0.265\). Therefore \(\partial L/\partial w_2=(p-y)h\approx-0.292\). Because \(z_1>0\), ReLU's local derivative is \(1\), so \(\partial L/\partial w_1=(p-y)w_2\phi'(z_1)x\approx(-0.265)(1.2)(1)(2)=-0.636\). Gradient descent subtracts these negative gradients, increasing both weights for this positive example and thereby tending to increase its predicted probability. At \(z_1<0\), the ReLU path would instead contribute zero gradient.

Use an MLP when inputs are fixed-length feature vectors or when a more specialized encoder has already produced such a vector. On small tabular datasets, compare it with classical models rather than assuming depth wins. Successful training requires differentiable—or almost everywhere differentiable—operations along the path being optimized, representative data, a suitable loss, and enough compute; none of these ensures causal understanding or safe extrapolation.

⚛ Physics bridge

Backpropagation is reverse-mode differentiation, closely related to the adjoint method in optimal control and sensitivity analysis. Rather than perturbing every parameter separately, it propagates one costate-like signal backward. Gradients through depth involve products of Jacobians, much like perturbations propagated through a dynamical system. Their singular values can amplify or contract directions, which connects exploding and vanishing gradients to stability analysis. Initialization, normalization, gating, and residual paths help keep useful sensitivity—but do not guarantee every Jacobian has norm exactly one.

5.2 The nonlinearity zoo and why initialization matters

Purpose — nonlinearities decide what signals and gradients can pass

If every layer were affine, then \(W_2(W_1x+b_1)+b_2\) could be collapsed into one affine layer. An activation prevents that collapse and shapes the derivative used in the backward pass. A good hidden activation is computationally practical, keeps useful gradients across the range the model visits, and works with the initialization and normalization scheme. Output activations have a different job: sigmoid represents a Bernoulli probability; softmax represents a categorical distribution; regression may need no output activation at all.

Initialization — preserve signal scale before learning begins

Identical zero weights make units in the same layer receive identical gradients, so they remain identical. Random initialization breaks that symmetry. Its scale matters: if independent inputs and weights are approximately zero-centred, then for one pre-activation \(z=\sum_{j=1}^{n_{in}}w_jx_j\), $$\operatorname{Var}(z)\approx n_{in}\operatorname{Var}(w)\operatorname{Var}(x).$$ A variance much smaller than the scale-preserving choice contracts signals layer by layer; a much larger variance amplifies them or drives saturating activations into flat tails.

SchemeCommon weight varianceUse and interpretation
Xavier / Glorot\(2/(n_{in}+n_{out})\)Balances forward and backward scale; common for tanh or roughly symmetric activations
He / Kaiming\(2/n_{in}\)Compensates approximately for ReLU discarding the negative half of a symmetric signal

Worked initialization calculation

With \(n_{in}=100\) and \(n_{out}=50\), Xavier variance is \(2/(100+50)=0.0133\), so a normal distribution would use standard deviation \(\sqrt{0.0133}\approx0.115\). He variance is \(2/100=0.0200\), giving standard deviation \(0.141\). Variance and standard deviation are not interchangeable. The estimate assumes independent, similarly distributed signals; trained networks soon violate those assumptions, so initialization is a starting condition rather than a permanent guarantee.

ReLU plus He initialization is a strong baseline for many convolutional networks. GELU or a gated block is common in transformer-style feed-forward layers, usually together with architecture- specific scaling and normalization. Sigmoid belongs naturally at a binary output or inside gates; tanh remains useful when bounded, signed state updates are desirable. Exact prescriptions depend on whether weights are transposed in storage, whether the calculation preserves forward or backward variance, and whether residual branches need additional depth scaling. Confirm the library's fan-in/fan-out convention rather than selecting a scheme by name alone.

5.3 Training deep networks — the stabilizer stack

Purpose — make useful gradient updates repeatably

Training is a feedback loop. The batch supplies a noisy estimate of the population gradient; the optimizer converts it into a step; the new weights change the next batch's activations and gradients. Instability can enter through data scale, layer depth, numerical precision, the learning rate, or the objective. The “stabilizer stack” addresses different parts of this loop—normalization controls internal scale, regularization constrains effective capacity, scheduling controls update size, and diagnostics reveal which mechanism has failed.

Optimizers and batches — what one step actually does

Plain stochastic gradient descent uses \(\theta_{t+1}=\theta_t-\eta g_t\), where \(g_t\) is the batch-average gradient and \(\eta\) is the learning rate. Momentum smooths recent directions. Adam maintains exponential averages of the gradient and squared gradient, corrects their initial bias, and scales each coordinate by its estimated root-mean-square. This often makes early optimization forgiving, but it does not remove the need to tune learning rate or monitor generalization. Small batches give noisier gradients and more updates per epoch; large batches give steadier estimates but use more memory and may require schedule adjustments.

Normalization — specify the axis before quoting the formula

For values \(x_i\) in the chosen normalization set \(S\), define $$\mu_S=\frac1{|S|}\sum_{i\in S}x_i,\qquad \sigma_S^2=\frac1{|S|}\sum_{i\in S}(x_i-\mu_S)^2,$$ $$\widehat x_i=\frac{x_i-\mu_S}{\sqrt{\sigma_S^2+\varepsilon}},\qquad y_i=\gamma\widehat x_i+\beta.$$ The small \(\varepsilon\) prevents division by zero. For one illustrated slice, \(\gamma,\beta\) can be read as scalars; actual layers normally learn one affine parameter pair per retained feature or channel and share it across the members being normalized. The important difference between methods is the set \(S\).

MethodValues normalized togetherTraining and inference behaviorBest-fit intuition and caveat

Worked normalization calculation

For \(x=(1,2,3)\), the mean is \(2\) and the population variance is \(2/3\). Ignoring a tiny \(\varepsilon\), mean-centred normalization gives approximately \((-1.225,0,1.225)\). RMSNorm uses \(\sqrt{(1^2+2^2+3^2)/3}=\sqrt{14/3}\approx2.160\), giving \((0.463,0.926,1.389)\). RMSNorm scales but does not centre, so its output mean need not be zero. In a real layer, learned scale—and sometimes offset—follows this calculation.

Warmup and cosine decay — control step size over time

During linear warmup, the learning rate may follow \(\eta_t=\eta_{\max}t/T_w\) for \(0\leq t\leq T_w\). Early gradients and Adam moment estimates can be highly variable, and deep residual or attention blocks may be sensitive to a full target rate before their parameters enter a stable regime. Warmup reduces that initial shock; it is a useful recipe, not a law and not a substitute for sound initialization. After warmup, one cosine schedule is $$\eta_t=\eta_{\min}+\frac12(\eta_{\max}-\eta_{\min}) \left[1+\cos\left(\pi\frac{t-T_w}{T-T_w}\right)\right].$$ It changes smoothly from large exploratory updates to smaller late updates. The minimum rate, warmup length, total step budget, and whether restarts are used remain hyperparameters.

Worked schedule calculation

Let \(\eta_{\max}=10^{-3}\), \(\eta_{\min}=10^{-5}\), \(T_w=100\), and \(T=1000\). At warmup step \(50\), \(\eta=5\times10^{-4}\). Halfway through the post-warmup interval, \(t=550\), the cosine is zero, so \(\eta=(10^{-3}+10^{-5})/2=5.05\times10^{-4}\). At \(t=1000\), it reaches \(10^{-5}\).

Normalization is most useful when internal scale makes optimization difficult; it is not a remedy for wrong labels. Dropout and weight decay address overfitting or brittle weights, not an inability to fit one batch. 5.4 Core architectures — matching structure to data

Purpose — put a useful structural assumption into the computation

Architecture is an inductive bias: it makes some relationships easier to represent than others. A convolution assumes local patterns should be detectable at many positions. A recurrent network assumes a state should be updated in sequence order. Attention assumes each item may retrieve information directly from a set of other items. An autoencoder assumes useful structure can be learned through a reconstruction task and a constrained representation. These assumptions reduce or reorganize the search space; none is automatically correct for every dataset.

Convolutional neural networks — local filters with shared parameters

For a two-dimensional input \(X\), output channel \(c_o\), and kernel \(K\), the operation commonly called convolution in deep-learning libraries is cross-correlation: $$Y_{i,j,c_o}=b_{c_o}+ \sum_{a=0}^{k_h-1}\sum_{b=0}^{k_w-1}\sum_{c_i=1}^{C_{in}} K_{a,b,c_i,c_o}\,X_{i s_h+a d_h-p_h,\;j s_w+b d_w-p_w,\;c_i}.$$ The same kernel values are reused at every valid output position: parameter sharing. Each output initially sees a local patch: local connectivity. A shift in the input generally shifts the feature map, so convolution is approximately translation equivariant away from boundary, stride, and sampling effects. Pooling or strided convolution reduces spatial size and compute and may increase tolerance to small shifts; it does not guarantee perfect invariance.

Along one spatial axis with input size \(n\), padding \(p\), kernel size \(k\), stride \(s\), and dilation \(d\), the output size is $$n_{out}=\left\lfloor\frac{n+2p-d(k-1)-1}{s}+1\right\rfloor.$$ A \(k_h\times k_w\) layer has \(k_hk_wC_{in}C_{out}+C_{out}\) trainable parameters when each output channel has a bias—independent of image width and height. The effective kernel or single-layer receptive-field width is \(d(k-1)+1\). Across layers, if \(r_l\) is receptive field and \(j_l\) is the spacing between adjacent features in input coordinates, \(r_l=r_{l-1}+(k_l-1)d_lj_{l-1}\) and \(j_l=j_{l-1}s_l\), starting from \(r_0=j_0=1\). In the displayed indexed sum, positions outside the stored input are defined as zero when zero-padding is used; other padding modes would change those boundary values.

Worked convolution shape and parameter calculation

For a \(32\times32\) RGB input, \(3\times3\) kernels, padding \(1\), stride \(1\), dilation \(1\), and \(16\) output channels, each spatial output size is \(\lfloor(32+2-2-1)/1+1\rfloor=32\). The output tensor per sample is \(32\times32\times16\). With biases, the parameter count is \(3\cdot3\cdot3\cdot16+16=448\), not \(32^2\) times that number, because the same \(448\) parameters are reused at every position.

RNNs — share one state-update rule across time

A vanilla recurrent neural network reads an ordered sequence using $$h_t=\phi(W_xx_t+W_hh_{t-1}+b_h),\qquad \widehat y_t=g(W_yh_t+b_y).$$ The same matrices are reused at every time step, so the hidden state summarizes the prefix seen so far. Training unfolds this computation across time and applies backpropagation through time. A gradient from time \(T\) to an earlier state includes a product \(\prod_{t=k+1}^{T}\partial h_t/\partial h_{t-1}\). Repeated singular values mainly below one contract many directions; values mainly above one can amplify them. This is why long-range credit assignment may vanish or explode even though the forward state appears finite.

LSTM gates create a controlled additive state path

One common LSTM form computes \(f_t=\sigma(W_f[x_t;h_{t-1}]+b_f)\), \(i_t=\sigma(W_i[x_t;h_{t-1}]+b_i)\), \(o_t=\sigma(W_o[x_t;h_{t-1}]+b_o)\), and \(\widetilde c_t=\tanh(W_c[x_t;h_{t-1}]+b_c)\), then $$c_t=f_t\odot c_{t-1}+i_t\odot\widetilde c_t,\qquad h_t=o_t\odot\tanh(c_t).$$ Along the direct cell-state path, holding the gate computation fixed, \(\partial c_t/\partial c_{t-1}=f_t\); across many steps the contribution contains a product of forget gates. Gates near one can preserve a path much better than an unconstrained recurrent matrix, but LSTMs mitigate rather than abolish vanishing gradients.

A conventional GRU uses \(r_t=\sigma(W_rx_t+U_rh_{t-1}+b_r)\), \(u_t=\sigma(W_ux_t+U_uh_{t-1}+b_u)\), \(\widetilde h_t=\tanh(W_hx_t+U_h(r_t\odot h_{t-1})+b_h)\), and \(h_t=(1-u_t)\odot h_{t-1}+u_t\odot\widetilde h_t\). It therefore blends retained state with a candidate without a separate cell state and usually has fewer parameters than an equally sized LSTM. Some sources reverse the update-gate convention or place the reset multiplication differently, so compare equations rather than gate names alone. 

state = initial_state
for each sequence position t in order:
    compute gates from current input and previous state
    compute a candidate update
    blend retained state with the candidate
    optionally emit an output at position t
backpropagate the sequence loss through the unrolled operations
mask padded positions so they do not affect loss or state

Use recurrence when streaming, bounded memory, or sequential state updates are central constraints. Carrying state between unrelated sequences causes leakage; always define when state resets. Very long sequences may still require clipping, truncated backpropagation, careful gates, or an attention-based alternative. Padding masks and sequence lengths are part of the mathematics, not cosmetic metadata.

Attention — content-based retrieval with explicit shapes

Given \(L\) input representations in \(X\in\mathbb R^{L\times d_{model}}\), one attention head forms \(Q=XW_Q\in\mathbb R^{L\times d_k}\), \(K=XW_K\in\mathbb R^{L\times d_k}\), and \(V=XW_V\in\mathbb R^{L\times d_v}\). Scaled dot-product attention is $$A=\operatorname{softmax}_{rows}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right), \qquad O=AV.$$ Each query row compares with every permitted key. Softmax makes its permitted weights nonnegative and sum to one, then the corresponding values are averaged. Dividing by \(\sqrt{d_k}\) prevents dot-product variance from growing with key dimension under simple independence assumptions. The mask \(M\) places a very negative value at forbidden pairs: padding masks hide nonexistent tokens, while causal masks prevent a position from reading future tokens.

Worked one-query attention calculation

Let \(q=(1,0)\), keys \(k_1=(1,0),k_2=(0,1)\), and values \(v_1=(2,0),v_2=(0,4)\). With \(d_k=2\), scaled scores are \((1/\sqrt2,0)\approx(0.707,0)\). Their softmax weights are approximately \((0.670,0.330)\), so the retrieved output is \(0.670v_1+0.330v_2\approx(1.340,1.320)\). A causal mask that forbade key 2 would change the weights to \((1,0)\), regardless of its score.

Dense self-attention forms an \(L\times L\) score matrix, requiring \(O(L^2d_k)\) score work and \(O(L^2)\) score storage per head before implementation refinements. It shortens interaction paths and permits parallel computation across positions during training, including with a causal mask. Autoregressive generation is still sequential across newly generated tokens. Attention alone has no notion of order, so position information must be supplied. It also does not guarantee interpretable or causal importance merely because a weight is large.

Autoencoders — learn by reconstructing a constrained input

An autoencoder contains an encoder \(z=f_\theta(x)\) and decoder \(\widehat x=g_\psi(z)\). A basic continuous-data objective is $$\min_{\theta,\psi}\frac1n\sum_{i=1}^{n} \left\|x_i-g_\psi(f_\theta(x_i))\right\|_2^2.$$ A bottleneck, noise corruption, sparsity penalty, or other constraint is intended to discourage the trivial strategy of copying every coordinate unchanged, although a sufficiently capable model can still learn a near-identity mapping. The latent \(z\) can support compression, anomaly scoring, denoising, visualization, or downstream features—but reconstruction rewards whatever reduces its loss, including nuisance details.

“Nonlinear PCA” is an analogy with conditions

For centred data, a linear encoder and decoder, squared reconstruction error, a bottleneck of the chosen dimension, and a global optimum, the optimal reconstructed subspace matches PCA's principal subspace. The latent coordinates and weights need not equal PCA's unique orthonormal loadings; invertible rotations within the bottleneck can give the same reconstruction. Nonlinear autoencoders can learn curved structure, but can also memorize if capacity overwhelms the constraint. Select bottleneck size and regularization on validation behavior relevant to the intended use.

Self-check

1. For one example with softmax probabilities \(\widehat y\), one-hot target \(y\), and cross-entropy loss, the gradient with respect to the logits is:

b. The derivatives combine to “predicted probability minus target.” For a batch-mean loss, average these per-sample logit gradients over the batch before propagating them to earlier layers.

2. What does a universal approximation theorem justify most directly?

d. This is an existence result. It does not supply a practical width, an optimization guarantee, a sample-complexity guarantee, or safe extrapolation outside the domain.

3. Which statement about hidden nonlinearities is correct?

c. ReLU's derivative is zero on its negative side and convention-dependent at zero. Sigmoid's maximum derivative is \(0.25\). No activation alone guarantees stable whole-network gradients.

4. A ReLU layer has fan-in \(200\). What is the usual He weight variance and approximate standard deviation?

a. He variance is \(2/n_{in}=2/200=0.01\); the normal-distribution standard deviation is its square root, \(0.10\).

5. Which normalization description is accurate?

b. Axis choice is the central distinction. BatchNorm normally changes from batch statistics in training to running estimates at inference; RMSNorm scales by root-mean-square without mean subtraction.

6. Which statement about regularization and scheduling is correct?

d. Inverted dropout is disabled at inference; validation chooses early stopping; AdamW decouples parameter shrinkage from Adam's adaptive gradient transformation.

7. A new model's classification loss remains near \(\log K\), and training accuracy stays at chance. What is the highest-value first diagnostic?

c. The tiny-batch test separates a broken optimization/data path from a generalization problem. If the model cannot memorize a few clean examples, regularizing it more is unlikely to help.

8. A convolution uses input size \(n=28\), kernel \(k=5\), padding \(p=2\), stride \(s=2\), and dilation \(d=1\). What is the output size along that axis?

a. \(\left\lfloor(28+4-4-1)/2+1\right\rfloor=\lfloor14.5\rfloor=14\). The floor matters whenever stride does not divide the available positions evenly.

9. Why can an LSTM retain gradients better than a vanilla RNN over many time steps?

d. The direct path contributes products of forget gates. Values near one can preserve sensitivity, but the product can still contract; an LSTM mitigates rather than permanently solves the problem.

10. Which combined statement about attention and autoencoders is correct?

b. Dense attention has quadratic score structure and needs masks plus position information. The PCA relation is conditional and concerns the reconstructed subspace; latent coordinates may be rotated.
