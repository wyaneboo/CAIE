Advanced Architectures: Transformers, Diffusion, GNNs

Level II begins with the architecture that ate the field. You will derive attention rather than admire it, account for every byte of the KV cache, and understand diffusion as a physicist should — as time-reversed Langevin dynamics. Vignettes here give you a company, a latency budget, and a sequence length, and ask which architectural lever to pull.

Learning outcomes
  • Derive scaled dot-product attention and explain the √d factor; decompose multi-head attention into Q/K/V projections and justify multiple heads.
  • Explain positional encodings (sinusoidal, learned, RoPE, ALiBi) and their extrapolation properties; describe the full transformer block and pre-LN vs post-LN.
  • Analyze attention's quadratic complexity; describe FlashAttention, sparse/linear/sliding-window variants; explain KV caching and MQA/GQA/paged attention.
  • Describe VAEs (reparameterization trick), GANs (minimax, mode collapse), diffusion models (forward/reverse, DDPM vs DDIM); compare diffusion vs autoregressive generation.
  • Describe GNN message passing and CLIP-style contrastive alignment.

8.1 Attention, derived

Topic 5 called attention a differentiable dictionary lookup. Now precisely: each token's embedding \(x_i\) is projected three ways — a query \(q_i = W_Q x_i\) ("what am I looking for?"), a key \(k_i = W_K x_i\) ("what do I contain?"), and a value \(v_i = W_V x_i\) ("what do I contribute if selected?"). Token \(i\)'s output is a similarity-weighted mixture of everyone's values: $$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V.$$

Why √d? If the components of \(q\) and \(k\) are independent with zero mean and unit variance, then \(q\cdot k = \sum_{j=1}^{d_k} q_j k_j\) has variance \(d_k\) — standard deviation \(\sqrt{d_k}\). At \(d_k = 128\), raw dot products routinely reach ±20, and softmax of ±20 is a one-hot vector: gradients through it vanish (every input change leaves the winner the winner). Dividing by \(\sqrt{d_k}\) restores unit variance — exactly the same signal-scale bookkeeping as Xavier initialization in Topic 5, applied to the attention logits. The widget below lets you watch saturation happen as \(d\) grows.

Why multiple heads? One softmax produces one convex mixture — one "relationship pattern" per layer. Splitting \(d_{model}\) into \(h\) heads of dimension \(d_{model}/h\), each with its own \(W_Q, W_K, W_V\), lets the layer attend to several relations simultaneously (a syntactic head, a coreference head, a positional head…), then concatenate and re-project. Cost is the same as one big head; expressivity is not.

The full block. A transformer layer is: \(x \mathrel{+}= \mathrm{MHA}(\mathrm{LN}(x))\); \(x \mathrel{+}= \mathrm{FFN}(\mathrm{LN}(x))\) — attention mixes information across positions; the FFN (typically 4× wider, GELU or SwiGLU) transforms each position independently; residual connections carry an identity path; normalization keeps scales sane. That's pre-LN (norm inside the residual branch), which trains stably deep because the residual stream is never normalized away. The original 2017 post-LN (norm after the addition) gives slightly better final loss but needs careful warmup and becomes fragile with depth — a classic exam contrast.

Positional encodings. Attention is permutation-invariant — without positional information, "dog bites man" = "man bites dog." Options, with their extrapolation behavior (what happens past training length):

SchemeMechanismExtrapolation
Sinusoidaladd fixed sin/cos waves of geometric frequencies to embeddingsdefined at any length, degrades in practice
Learned absolutea trained embedding per position indexnone — position 4097 literally has no vector
RoPE (rotary)rotate each q,k pair by an angle ∝ position; dot products then depend only on relative offsetmoderate; extendable via interpolation/YaRN tricks — the modern default (Llama, Qwen)
ALiBino embedding at all; subtract a linear distance penalty from attention logits per headbest zero-shot length extrapolation; biases toward recency
⚛ Physics bridge

RoPE is phase encoding: a pair of embedding dimensions is treated as a complex number and position is a rotation \(e^{i m\theta}\) — so \(\langle q_m, k_n\rangle\) depends only on the phase difference \((m-n)\theta\), like an interference pattern depending only on path difference. Sinusoidal encoding is a Fourier basis over position. And attention itself — \(\mathrm{softmax}(E/T)\) weights over states — is a Boltzmann distribution over which past token to "occupy," with the √d factor setting the temperature.

The quadratic problem and its industry. \(QK^\top\) is an \(n \times n\) matrix: \(O(n^2 d)\) time and — naively — \(O(n^2)\) memory. At 128k context that matrix has 1.6×10¹⁰ entries per head per layer. The main responses:

  • FlashAttention — exact attention, restructured: compute \(QK^\top\) tile by tile in fast on-chip SRAM, using the online-softmax trick so the full matrix never touches slow HBM memory. It's a memory-hierarchy optimization (Topic 3!), not an approximation: 2–4× faster, \(O(n)\) memory, identical output.
  • Sliding-window / sparse — attend only to the last w tokens or to a structured subset (Mistral's 4k window; Longformer's global+local): \(O(nw)\). Long range flows through stacked layers' growing receptive field, CNN-style.
  • Linear attention — replace softmax with a kernel feature map so \((\phi(Q)\phi(K)^\top)V\) can be reassociated to \(\phi(Q)(\phi(K)^\top V)\): \(O(n)\), but quality lags at equal size; the idea lives on in state-space/hybrid models (Mamba-class).

KV caching is the inference-side twin. Generating token \(t\) needs attention over all previous keys/values; recomputing them each step would make generation \(O(n^2)\) per token. So you cache K and V for every layer — and that cache, not the weights, is what limits batch size at long context: $$\text{KV bytes} = 2 \times L \times n_{kv} \times d_{head} \times S \times B \times \text{bytes/param}.$$ Shrinking it: MQA (all query heads share 1 K/V head), GQA (groups share — e.g. 64 query heads, 8 KV heads: 8× smaller cache, negligible quality loss — the Llama-70B choice), and paged attention (vLLM): store the cache in non-contiguous pages like virtual memory, eliminating fragmentation so real serving batches fit.

8.2 Generative architectures — three ways to invent data

Generative modeling asks for samples from \(p(x)\). Three families, three strategies:

VAEs pair a probabilistic encoder \(q(z\mid x)\) with a decoder \(p(x\mid z)\) and maximize the ELBO: reconstruction quality minus \(D_{KL}(q(z\mid x)\,\|\,\mathcal N(0,I))\), which keeps the latent space organized so you can sample from the prior. The reparameterization trick solves "how do you backprop through sampling?": instead of sampling \(z \sim \mathcal N(\mu, \sigma^2)\) — a stochastic node with no gradient — compute \(z = \mu + \sigma \odot \epsilon\), \(\epsilon \sim \mathcal N(0, I)\). Randomness moves into an input; \(\mu\) and \(\sigma\) sit on a clean differentiable path. VAEs sample fast and embed meaningfully, but reconstructions blur (the Gaussian likelihood averages modes).

GANs stage a two-player game: a generator maps noise to fakes, a discriminator classifies real vs fake, \(\min_G \max_D \; E[\log D(x)] + E[\log(1 - D(G(z)))]\). At equilibrium the generator matches the data distribution. In practice the game oscillates and suffers mode collapse: the generator finds a few outputs that reliably fool the current discriminator and abandons the rest of the distribution — the canonical symptom is a face model producing thirty near-identical faces. Sharp samples, treacherous training, no likelihoods.

Diffusion models — the current image-generation standard — define a forward process that gradually gaussianizes data over T steps, \(x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon\), and train a network \(\epsilon_\theta(x_t, t)\) to predict the added noise — a simple regression loss, no adversary. Generation runs the process backward: start from pure noise, repeatedly subtract predicted noise. DDPM sampling is the faithful stochastic reversal (~1000 steps); DDIM reinterprets the same trained network as a deterministic ODE and takes 20–50 big steps — the standard fast sampler. Training is stable, coverage is excellent, and the cost is many network evaluations per sample.

⚛ Physics bridge

The forward process is an Ornstein–Uhlenbeck relaxation toward an isotropic Gaussian — structure diffusing away exactly as in the heat equation. The reverse process follows the score \(\nabla_x \log p_t(x)\) (Anderson's time-reversal theorem): denoising is reverse Langevin dynamics, and the noise-prediction network is secretly learning the score field. DDIM is the associated probability-flow ODE — same marginals, no noise. If you've integrated Fokker–Planck equations, you already own the mathematics of Stable Diffusion.

Diffusion vs autoregressive — the tradeoff table the exam wants: AR models (GPT-style) factorize \(p(x) = \prod_i p(x_i \mid x_{<i})\): exact likelihoods, natural for discrete sequences, streaming generation, but serial decoding (one token at a time). Diffusion: parallel over all positions per step but many steps, natural for continuous data (images, audio), supports inpainting/editing via partial noising, weaker at discrete text. Rule of thumb: language → AR; images/audio/video → diffusion (usually latent diffusion — Topic 10); molecules and structured continuums → diffusion's home turf too.

8.3 Graphs and multimodality

GNNs. When data is a graph (molecules, social networks, road maps), the architecture should respect its symmetry — permutation of node labels — exactly as CNNs respect translation. Message passing: each round, every node aggregates its neighbors' vectors with a permutation-invariant reduction (sum/mean/max) and updates its own: $$h_v^{(k+1)} = \phi\Big(h_v^{(k)}, \bigoplus_{u \in N(v)} \psi(h_u^{(k)}, e_{uv})\Big).$$ After k rounds a node has seen its k-hop neighborhood — a receptive field over graph structure. (GCN/GraphSAGE/GAT differ in the aggregation; GAT uses attention weights over neighbors, and a transformer is, in this language, a GNN on the fully-connected token graph.) Caveats worth knowing: over-smoothing (too many rounds → all nodes converge to the same vector) and over-squashing (long-range information bottlenecked through few edges).

CLIP-style contrastive alignment. To join vision and language, train an image encoder and a text encoder on N (image, caption) pairs per batch with a symmetric InfoNCE loss: make each image's embedding most similar to its own caption among all N (softmax over similarities, both directions). No pixel labels — just co-occurrence. The result is a shared embedding space where "a photo of a dog" lands near dog photos: zero-shot classification (compare an image against label prompts), retrieval, and the text-conditioning backbone that diffusion models use to understand prompts. This one loss function is the joint that connects Topics 8, 10, and 14.

Jargon decoder
residual stream
The running sum flowing through a transformer's skip connections; each block reads from and writes into it. Central to interpretability work (Topic 15).
HBM / SRAM
GPU main memory (large, slow) vs on-chip cache (tiny, fast). FlashAttention is the art of staying in SRAM.
ELBO
Evidence Lower BOund — the VAE objective: reconstruction − KL. Maximizing it maximizes a lower bound on log-likelihood.
score function
\(\nabla_x \log p(x)\) — the vector field pointing toward higher data density; what diffusion models implicitly learn.
InfoNCE
The contrastive loss: cross-entropy of picking the true pair among in-batch negatives.
context window
Maximum sequence length a model processes; extending it is a PE + memory + data problem simultaneously.
Mamba / SSM
State-space models: linear-time sequence architectures with a recurrent (constant-memory) inference mode — the main non-attention challenger.

Self-check

1. Without the √d scaling, attention at large d fails because:

b. Var(q·k)=d for unit-variance components; softmax of ±√d·z saturates. (Overflow (a) can also eventually happen, but the gradient-death mechanism is the designed-for reason.)

2. FlashAttention achieves its speedup by:

c. It is exact — an IO-complexity result, not an approximation. Distinguishing "faster exact" from "cheaper approximate" methods is a favorite exam discriminator.

3. A 64-head model switches from MHA to GQA with 8 KV heads. The KV cache shrinks by:

a. Cache = 2·L·n_kv·d_head·S·B·bytes. n_kv drops 64→8. Verify on the calculator above.

4. Your GAN generates excellent portraits — but only about a dozen distinct faces. This is:

d. Mode collapse is the signature GAN pathology (posterior collapse (b) is the VAE one — worth keeping straight for the exam). Coverage guarantees are a core reason the industry moved to diffusion.
