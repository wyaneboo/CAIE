Computer Vision

A vision model turns spatial measurements into decisions: a class for an image, boxes for objects, labels for pixels, or a new image conditioned on text and geometry. The recurring questions are concrete: what is the tensor shape, which pixels can influence an output, what supervision is available, and which errors matter after deployment?

Learning outcomes
  • Describe ResNet skip connections and EfficientNet compound scaling.
  • Explain Vision Transformers and patch embeddings.
  • Describe detection (YOLO, Faster R-CNN) and segmentation (U-Net, Mask R-CNN).
  • Apply transfer learning/fine-tuning; describe augmentation and its regularizing effect.

Orientation — read an image as a tensor

One sample is commonly written \(x\in\mathbb{R}^{H\times W\times C}\): height, width, and channels. Libraries may store a batch as \(N\times C\times H\times W\) instead. The ordering is a convention; the meaning is not. A feature map has spatial positions and learned channels. A kernel slides locally; stride moves it, padding extends the boundary, and dilation spreads its taps. A backbone extracts features, an optional neck fuses scales, and a head produces task-specific outputs.

Orientation — training evidence and spatial bookkeeping

Training estimates parameters from a training set; validation selects architecture, thresholds, and augmentations; the test set is opened only for final evaluation. For grouped or repeated images, split by patient, camera, scene, or source—not by file—so near-duplicates cannot cross folds. Before interpreting any architecture, write the input shape, output shape, coordinate convention, label grain, and split unit. Most vision mistakes are visible in that five-line audit.

Worked orientation

A batch of 32 RGB images resized to \(224\times224\) is \(32\times3\times224\times224\) in channels-first notation. A ten-class head returns \(32\times10\) logits. A semantic head for the same ten classes returns \(32\times10\times224\times224\) logits before per-pixel argmax.

10.1 Modern CNN backbones

Residual blocks — learn a correction, preserve a direct route

A plain deep stack must learn every transformation, including identity. A residual block instead computes \(y=\sigma(F(x;\theta)+S(x))\), where \(S(x)=x\) when shapes match. The derivative contains a direct term: \(\partial y/\partial x\) includes the skip path in addition to the residual branch. This improves optimization, but it does not make gradients immune to poor normalization, activation saturation, or an unstable residual branch.

Worked residual calculation

If one scalar channel has \(x=2.0\) and the learned residual is \(F(x)=-0.3\), the pre-activation output is \(1.7\). If \(F\) is initially near zero, the block is near identity, which is an easier starting behavior than forcing several nonlinear layers to reconstruct \(x\).

RESIDUAL_BLOCK(x):
  residual = CONV_NORM_ACT(x)
  residual = CONV_NORM(residual)
  skip = x if shape(residual) == shape(x)
         else PROJECT_1x1(x, target_channels, target_stride)
  return ACTIVATE(skip + residual)

Skip-path shape rules — addition is not concatenation

Elementwise addition requires identical spatial and channel shapes. When a block halves resolution or changes channels, \(S\) is commonly a \(1\times1\) convolution with the required stride. A U-Net skip is different: it usually concatenates encoder features with decoder features, increasing channels. Confusing these operations produces silent architecture errors.

Convolution arithmetic — spatial size and parameter count

For one spatial dimension, effective kernel size is \(k_{\mathrm{eff}}=d(k-1)+1\), and \(n_{\mathrm{out}}=\left\lfloor(n+2p-k_{\mathrm{eff}})/s\right\rfloor+1\). A dense \(k\times k\) convolution with bias has \(k^2C_{\mathrm{in}}C_{\mathrm{out}}+C_{\mathrm{out}}\) parameters. Parameters do not grow with image area, although activation memory and compute do.

EfficientNet — scale depth, width, and resolution together

The original compound rule uses \(d=\alpha^\phi\), \(w=\beta^\phi\), and \(r=\gamma^\phi\), with \(\alpha\beta^2\gamma^2\approx2\) under a rough convolutional-FLOP model. Increasing \(\phi\) by one then targets about twice the compute. Channel and layer counts must be rounded to valid architecture values, so the realized model only approximates the equation. EfficientNet also depends on its searched baseline and mobile inverted bottleneck blocks; compound scaling is not a guarantee that every model family scales optimally.

Receptive field — what can one output unit see?

Track both the receptive field \(r_l\) and the input-space jump \(j_l\): \(j_l=j_{l-1}s_l\) and \(r_l=r_{l-1}+(k_l-1)d_lj_{l-1}\), starting from \(r_0=j_0=1\). This is the theoretical receptive field; the effective influence observed in a trained network is often concentrated nearer the center.

10.2 Vision Transformers

Patch embedding — convert spatial blocks into tokens

For patch size \(P\) that divides \(H\) and \(W\), an image becomes \(N=(H/P)(W/P)\) patches. Each flattened patch has \(P^2C\) values and a shared linear layer maps it to embedding width \(D\). A learned class token is optional; many systems pool patch tokens instead. Positional information must be added or encoded because self-attention alone is permutation-equivariant.

Worked ViT shape

A \(224\times224\times3\) image with \(P=16\) gives \(14\times14=196\) patches. Each patch has \(16^2\cdot3=768\) values. With a class token there are 197 tokens and \(197^2=38{,}809\) ordered query-key pairs per attention head.

Self-attention — global mixing with quadratic token interactions

For token matrix \(X\in\mathbb{R}^{T\times D}\), one head forms \(Q=XW_Q\), \(K=XW_K\), \(V=XW_V\), then \(\operatorname{softmax}(QK^\top/\sqrt{d_h})V\). The attention matrix is \(T\times T\). Halving patch size in both dimensions quadruples \(T\) and increases attention-pair storage about sixteen-fold. Total block cost also includes projections and MLPs, so \(T^2\) is not the whole runtime model. 

VIT_FORWARD(image):
  patches = NONOVERLAPPING_PATCHES(image, patch_size)
  tokens = LINEAR_PROJECT(flatten(patches))
  tokens = OPTIONAL_CLASS_TOKEN(tokens) + POSITION_ENCODING
  repeat encoder blocks:
      tokens = tokens + MULTIHEAD_ATTENTION(NORM(tokens))
      tokens = tokens + MLP(NORM(tokens))
  return CLASS_HEAD(pool(tokens))

CNN or ViT? Match inductive bias, data, and deployment

CNN locality and translation equivariance are strong priors and often data-efficient. ViTs provide flexible global interaction and scale well with large pretraining, but plain global attention can be expensive at high resolution. Modern systems blur the boundary with convolutional stems, hierarchical/windowed attention, and hybrid backbones. Do not use a remembered dataset-size cutoff: compare pretrained checkpoints, resolution, latency, memory, and shift on the actual task.

10.3 Detection and segmentation — one backbone, different heads

Detection output — a scored set, not one class

A detector predicts box coordinates, objectness, and class scores at many candidate locations. Coordinates may be corners \((x_1,y_1,x_2,y_2)\) or center-size \((c_x,c_y,w,h)\); conversion and clipping must be explicit. Training matches predictions to ground-truth objects. Evaluation uses one-to-one matching, so two predictions cannot both claim the same object.

IoU and non-maximum suppression — overlap has geometry

For boxes \(A\) and \(B\), \(\operatorname{IoU}=|A\cap B|/(|A|+|B|-|A\cap B|)\). IoU is zero for disjoint boxes and one for identical boxes. NMS sorts predictions by score, keeps the highest, and suppresses sufficiently overlapping lower-scored boxes. Its threshold is a deduplication hyperparameter, not the same thing as the evaluation IoU threshold.

GREEDY_NMS(boxes, scores, threshold):
  order candidates by descending score
  kept = []
  while candidates remain:
      best = remove first candidate
      append best to kept
      remove remaining candidates with IoU(best, candidate) > threshold
  return kept

YOLO — one-stage dense prediction

YOLO-family detectors predict boxes and class evidence directly over dense feature maps, commonly at several scales. “One stage” means no separate learned proposal-and-classification pipeline; it does not mean one output box per grid cell or one universal loss across YOLO versions. The design favors throughput and simple deployment, but small objects, crowded scenes, label assignment, and post-processing still require careful evaluation.

Faster R-CNN — proposals followed by per-region refinement

A Region Proposal Network produces object candidates from shared features. RoI pooling/alignment converts each candidate to a fixed-size feature, and a second-stage head classifies and refines it. This two-stage structure is often a strong accuracy baseline, especially when proposal quality matters, but latency depends on backbone, proposal count, resolution, and hardware—not the family name alone.

Detection metrics — precision-recall after ranked matching

At a declared IoU rule, score-sorted predictions become true or false positives through one-to-one matching. Precision is \(TP/(TP+FP)\); recall is \(TP/N_{\mathrm{gt}}\). Average Precision is area under a ranked precision-recall curve under a specified interpolation convention. mAP averages AP across classes and, in some protocols, across multiple IoU thresholds. Always name the protocol: “mAP” alone is incomplete.

Guided calculation — ranked detections and AP
Each line is score,match where match is 1 or 0 after one-to-one matching at a declared IoU threshold.

The lab uses an all-points precision envelope. COCO-style AP uses a specified set of recall points and averages across IoU thresholds, so numbers from different protocols are not interchangeable.

Segmentation tasks — semantic, instance, and panoptic

Semantic segmentation assigns a class to every pixel but merges same-class objects. Instance segmentation separates individual countable objects. Panoptic segmentation combines “stuff” regions such as sky with distinct “thing” instances. The output choice follows the decision: measuring total road area needs semantic masks; counting touching cells needs instances.

U-Net and Mask R-CNN — two different mask pipelines

U-Net contracts spatial size to gather context, then upsamples while concatenating aligned high-resolution encoder features. It naturally produces dense semantic logits. Mask R-CNN extends Faster R-CNN with a per-RoI mask head, producing a separate mask for each detected instance. U-Net variants can perform instance segmentation with additional targets, and Mask R-CNN can be adapted, but their canonical supervision and output grains differ. 

U_NET_FORWARD(image):
  skips = []
  x = image
  for encoder level:
      x = CONV_BLOCK(x)
      save x in skips
      x = DOWNSAMPLE(x)
  for decoder level in reverse:
      x = UPSAMPLE(x)
      x = CONCAT(x, aligned encoder skip)
      x = CONV_BLOCK(x)
  return PER_PIXEL_CLASS_LOGITS(x)

Segmentation metrics — count pixels without hiding the foreground

Foreground IoU is \(TP/(TP+FP+FN)\); Dice is \(2TP/(2TP+FP+FN)\). Dice and IoU are monotonically related for one binary mask: \(\mathrm{Dice}=2\mathrm{IoU}/(1+\mathrm{IoU})\). Pixel accuracy can look excellent when background dominates, so report per-class metrics, uncertainty, and boundary-sensitive errors where geometry matters.

10.4 Transfer learning and augmentation

Transfer ladder — head-only, partial, then full fine-tuning

Start with a checkpoint whose source data and modality are defensible. With scarce labels, freeze the backbone and train a new head. Then unfreeze later blocks with a smaller learning rate; unfreeze more only when validation evidence supports it. Reinitialize task heads, decide whether normalization statistics update, and use parameter groups rather than one learning rate for every layer. “Early edges, late semantics” is a useful intuition, not a law for every architecture.

Worked parameter budget

A 25-million-parameter backbone with a 20,500-parameter head trains only about \(20{,}500/25{,}020{,}500\approx0.082\%\) of parameters in a linear-probe phase. This reduces optimization degrees of freedom, but activations may still consume substantial memory.

TRANSFER_WORKFLOW(data):
  split by real deployment entity before preprocessing
  load a compatible pretrained backbone
  train a new head; select using validation evidence
  unfreeze the last stage with a smaller backbone learning rate
  compare against the frozen baseline on calibration and subgroup slices
  unfreeze further only if benefit exceeds instability and compute cost
  evaluate once on untouched test data

Augmentation — encode justified invariances

Random crops, flips, color changes, erasing, MixUp, CutMix, and policy-based transforms can regularize by presenting a neighborhood of plausible inputs. Each transform asserts something about the label. A horizontal flip is safe for many natural-object classes but can corrupt text, laterality, traffic orientation, or anatomy. Detection and segmentation require transforming boxes and masks with the image. Validation and test data use deterministic preprocessing, not random training augmentation.

Failure modes — leakage, shift, calibration, and shortcuts

Vision models exploit easy correlates: hospital tokens, rulers, borders, compression, camera type, or background. Audit performance by source, time, device, geography, and acquisition protocol. Inspect saliency only as a diagnostic—not proof of causality. Test corruptions and out-of-domain data, calibrate confidence on validation data, and establish an abstention or human-review path when uncertainty has operational meaning.

Scaling warning

Higher input resolution grows activation memory roughly with pixel count; global ViT attention can grow quadratically with token count. Measure batch-one latency and peak memory on deployment hardware. Training throughput is not serving latency.

10.5 Generation: latent diffusion pipelines

Latent diffusion — compress, denoise, decode

A variational autoencoder maps pixels \(x\) to a lower-resolution latent \(z\). A denoiser predicts noise, velocity, or another scheduler-defined target over noisy latents while conditioning on text or other signals. Iterative sampling produces \(z_0\), then the decoder returns pixels. Compression makes spatial denoising cheaper, but the VAE can lose small text, faces, and fine structure; latent element ratio is not the same as end-to-end FLOP or memory ratio.

TEXT_TO_IMAGE(prompt):
  condition = TEXT_ENCODER(prompt)
  z = SAMPLE_LATENT_NOISE()
  for scheduler timestep t:
      prediction = DENOISER(z, t, condition)
      z = SCHEDULER_UPDATE(z, prediction, t)
  return VAE_DECODER(z)

Editing — img2img, inpainting, and spatial controls

Img2img encodes a source image, adds noise to a chosen strength, then denoises under new conditioning: more noise permits larger changes but preserves less structure. Inpainting repeatedly constrains unmasked regions while generating inside a mask. ControlNet-style modules inject edges, depth, pose, or other spatial evidence. Cross-attention connects condition tokens to image features; classifier-free guidance trades condition adherence against diversity and can produce artifacts when pushed too far.

Generation decision guide — quality is not one scalar

Choose the pipeline by constraint: text-to-image for open synthesis, img2img for appearance changes, inpainting for localized replacement, and explicit spatial conditioning for layout. Evaluate prompt adherence, diversity, identity/privacy risks, memorization, bias, safety filters, provenance, and downstream task utility. FID-like distribution metrics cannot certify factuality, consent, or individual-image quality.

Physics bridge

Convolution encodes locality and translation structure; augmentation declares approximate symmetries; diffusion integrates a learned reverse stochastic process. In every case, the model works because structure narrows the space of functions worth considering.

2. A \(32\times32\) input uses a 3×3, dilation-1 convolution with padding 1 and stride 2. Its spatial output is:

c. \(\lfloor(32+2-3)/2\rfloor+1=16\).

3. Changing ViT patch size from 16 to 8 at fixed image size approximately changes global-attention pair count by:

d. Tokens quadruple because both spatial axes double; pair count is quadratic, so it grows about \(4^2=16\) times.

4. Which statement correctly compares canonical YOLO and Faster R-CNN pipelines?

a. The pipeline distinction is structural; actual AP and latency must be measured for the chosen models and hardware.

5. Two 10×10 boxes overlap in a 5×10 strip. Their IoU is:

b. Intersection is 50 and union is \(100+100-50=150\), so IoU is \(50/150=1/3\).

6. Why is “mAP = 0.52” incomplete reporting?

c. Different protocols can produce different AP values from the same ranked detections.

7. You must count touching cells separately. The most direct canonical starting task/model is:

d. Instance masks keep same-class objects separate; a semantic mask merges them.

8. For TP=60, FP=20, FN=10, foreground Dice is:

a. \(2TP/(2TP+FP+FN)=120/150=0.80\). IoU is \(60/90=0.667\).

9. A laterality-sensitive medical dataset has 800 labeled images. A defensible starting workflow is:
