Reinforcement Learning

Reinforcement learning studies decisions whose consequences unfold over time. An agent acts, observes what follows, and uses reward as a learning signal. The hard part is not merely finding a high score: it is assigning credit across time, exploring safely, and knowing which policy the data can validly improve.

Orientation — the vocabulary of one interaction

At time \(t\), the agent receives an observation \(o_t\), represents a state \(s_t\), chooses an action \(a_t\) from a policy \(\pi(a\mid s)\), and receives reward \(r_{t+1}\). The environment then moves to \(s_{t+1}\). A trajectory is the resulting sequence; a complete trajectory is often called an episode. Reward is one step's signal. Return is the discounted sum the objective actually values.

Orientation — two independent algorithm axes

Model-based versus model-free asks whether planning uses transition/reward dynamics. On-policy versus off-policy asks whether learning evaluates the same policy that generated the data. These axes are independent: a method can be model-free and on-policy (SARSA), model-free and off-policy (Q-learning), or model-based with either data policy.

11.1 The MDP formalism and the Bellman equations

MDP components — make the state sufficient

A Markov decision process is \((\mathcal S,\mathcal A,P,R,\gamma)\), with \(P(s'\mid s,a)\) and an expected reward convention such as \(R(s,a,s')\). The Markov property says that, conditioned on the current state and action, earlier history adds no predictive information about the next state. It is a modeling requirement, not a claim that raw sensor readings always satisfy it. If the observation hides relevant information, use history, a belief state, recurrence, or a partially observable MDP.

Worked formulation — inventory control

State can include on-hand stock, outstanding orders, and time; action is order quantity; reward is sales margin minus holding, shortage, and order costs; transition combines demand and delivery; \(\gamma\) values later profit. If outstanding orders are omitted, identical visible stock can lead to different futures, so “stock alone” is not Markov.

Return and horizon — discounting is a decision choice

With reward arriving after action \(a_t\), define \(G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k+1}\). A smaller \(\gamma\) shortens the effective horizon; a useful scale is roughly \(1/(1-\gamma)\) for continuing problems. Usually \(0\le\gamma<1\) makes bounded continuing returns finite. A finite or proper episodic task can also use \(\gamma=1\). Changing \(\gamma\) changes the objective unless it is only compensating for a formal horizon convention.

Worked return

For rewards \(2,1,4\) and \(\gamma=0.5\), the three-step return is \(2+0.5(1)+0.5^2(4)=3.5\). Reward \(2\) is not the return; the later two outcomes still matter.

Termination and truncation — decide whether to bootstrap

Termination means the MDP reached a terminal condition, so the continuation value is zero. Truncation means data collection stopped for an external reason, such as a simulator time limit, while the underlying process may continue; bootstrapping is usually then appropriate. If the time limit is itself part of the task, include remaining time in state and treat the horizon as terminal. Storing only a single “done” flag can silently bias TD targets.

Bellman expectation equations — evaluate one policy

Splitting return after one step gives a recursive consistency equation: $$ V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a) \left[R(s,a,s')+\gamma V^\pi(s')\right]. $$ Similarly, \(Q^\pi(s,a)=\mathbb E[r_{t+1}+\gamma Q^\pi(s_{t+1},a_{t+1})]\) with \(a_{t+1}\sim\pi\). The expectation covers both environmental randomness and policy randomness.

Bellman optimality — choose the best continuation

The optimal value replaces policy averaging with maximization: $$ V^*(s)=\max_a\sum_{s'}P(s'\mid s,a) \left[R(s,a,s')+\gamma V^*(s')\right], \qquad V^*(s)=\max_a Q^*(s,a). $$ Evaluation and control are different jobs. The expectation equation asks “how good is this policy?” The optimality equation asks “what is the best achievable return?” A maximum over noisy estimates can be optimistically biased, a point that returns in Double DQN.

Value iteration — repeated optimality backups

For a finite discounted MDP with a known model, synchronous value iteration applies the Bellman optimality operator to every state, then replaces the old table. The exact operator is a \(\gamma\)-contraction under the sup norm when \(\gamma<1\), so repeated exact backups approach the unique fixed point. Approximate function fitting, sampling noise, or changing dynamics do not inherit that guarantee automatically. 

VALUE_ITERATION(model, tolerance):
  initialize V(s)
  repeat:
    old = copy(V)
    for each nonterminal state s:
      V(s) = max over actions of EXPECTED_REWARD_PLUS_DISCOUNTED(old, s, a)
    delta = max over states of abs(V(s) - old(s))
  until delta < tolerance
  return a policy greedy with respect to V

Policy iteration — evaluate, then improve

Policy iteration alternates two operations: solve or approximate \(V^\pi\) for the current policy, then make the policy greedy with respect to that value. Exact policy evaluation may take many sweeps or a linear solve; modified policy iteration uses only a few evaluation sweeps. In small tabular problems policy iteration often needs fewer improvement rounds than value iteration, but each round is more expensive. Neither is automatically preferable on every MDP. 

POLICY_ITERATION(model):
  initialize policy pi
  repeat:
    evaluate V_pi for pi
    improved = GREEDY_POLICY(V_pi, model)
    stable = every improved action matches pi
    pi = improved
  until stable
  return pi, V_pi
⚛ Physics bridge

Bellman equations are discrete relatives of Hamilton–Jacobi–Bellman equations. Value iteration is fixed-point relaxation: reward information propagates backward through the state graph, attenuated by transition probabilities and \(\gamma\). The analogy is useful, but values are expectations under decisions—not conserved fields—and approximation can break the clean contraction picture.

11.2 Model-free control — learning Q from experience

Temporal-difference learning — update before the episode ends

TD learning bootstraps: it moves an estimate toward a reward plus another estimate. For a target \(Y_t\), the TD error is \(\delta_t=Y_t-Q(s_t,a_t)\), and the update is \(Q\leftarrow Q+\alpha\delta_t\). Monte Carlo methods wait for a sampled return and do not bootstrap; dynamic programming bootstraps from an expectation under a known model. TD occupies the useful middle: sampled experience plus bootstrapping.

Q-learning and SARSA — target policy changes the backup

Q-learning uses \(Y^{Q}=r+\gamma\max_{a'}Q(s',a')\), so it is off-policy: exploratory behavior can generate data while the backup evaluates a greedy target. SARSA uses \(Y^{S}=r+\gamma Q(s',a')\) for the next action actually selected, so it is on-policy. In cliff-walking with persistent \(\varepsilon\)-greedy behavior, SARSA can value a safer route because its target includes future exploratory mistakes; Q-learning values the greedy route. That example is illustrative, not a universal ranking.

Tabular convergence — state the assumptions

In a finite stationary MDP with \(\gamma<1\) (or an appropriate proper episodic setting), tabular Q-learning converges to \(Q^*\) under standard conditions: every state–action pair is visited sufficiently often, rewards are bounded, and learning rates satisfy stochastic-approximation conditions such as \(\sum_t\alpha_t=\infty\) and \(\sum_t\alpha_t^2<\infty\). A constant learning rate is useful for tracking but does not meet the classic almost-sure convergence statement. Function approximation, partial observability, finite replay, and nonstationarity require separate evidence.

The deadly triad

Function approximation, bootstrapping, and off-policy training can interact to make values diverge. DQN's stabilizers reduce this risk; they do not turn neural Q-learning into a guaranteed contraction.

DQN — approximate Q without chasing every target immediately

DQN represents \(Q(s,a;\theta)\) with a neural network. Experience replay decorrelates samples and reuses data; a lagged target network \(\theta^-\) holds the bootstrap target comparatively still: \(Y=r+\gamma\max_{a'}Q(s',a';\theta^-)\). DQN is model-free and off-policy. It is most natural for discrete action sets because the max enumerates or searches actions. 

DQN_UPDATE(replay, online, target):
  sample transitions from replay
  for each transition:
    if truly terminal: y = reward
    else: y = reward + gamma * max_a target(next_state, a)
  minimize mean squared or Huber loss between y and online(state, action)
  periodically or softly update target from online

Double DQN and replay caveats — stabilizers have scope

DQN's same noisy values select and evaluate the maximizing action, which can create maximization bias. Double DQN selects \(a^*=\arg\max_a Q(s',a;\theta)\) with the online network but evaluates it using \(Q(s',a^*;\theta^-)\). Replay distribution can still overrepresent old behavior, duplicate transitions, or unsafe logging policies. Prioritized replay changes the sampling distribution and normally needs importance weighting to correct its bias.

11.3 Policy gradients — optimize the behavior directly

REINFORCE — differentiate log-probability, weight by return

For a differentiable stochastic policy, the likelihood-ratio identity yields $$ \nabla_\theta J(\theta)= \mathbb E_{\tau\sim\pi_\theta}\left[ \sum_t G_t\nabla_\theta\log\pi_\theta(a_t\mid s_t) \right]. $$ Positive return increases the sampled action's log-probability; negative return decreases it. REINFORCE is an on-policy Monte Carlo estimator: conceptually simple and often high variance. Continuous actions are possible when the policy defines a density, such as a Gaussian. 

REINFORCE:
  collect complete trajectories with current policy
  compute return G_t for every step
  accumulate (G_t - baseline(s_t)) * gradient log policy(a_t | s_t)
  update policy by gradient ascent
  discard or carefully correct stale on-policy data

Baselines and advantages — reduce variance without changing the expected gradient

Subtracting an action-independent baseline \(b(s)\) leaves the expected policy gradient unchanged because \(\mathbb E_{a\sim\pi}[\nabla\log\pi(a\mid s)]=0\). The signal \(G_t-b(s_t)\) estimates advantage: performance above or below expectation. The theorem concerns expectation and an action-independent baseline. A baseline that depends on the sampled action without correction can bias the gradient, and a finite batch need not have exactly zero mean score.

A2C — actor and critic learn together

An actor–critic uses a policy actor and a value critic. A2C commonly collects synchronized batches from parallel environments, forms one-step or \(n\)-step bootstrapped advantages, updates the actor with those advantages, and fits the critic to return targets. It remains on-policy in its standard form. A poor critic can add bias to bootstrapped advantage estimates, so value loss, advantage normalization, entropy, and rollout length are monitored rather than treated as decoration.

PPO — a clipped surrogate, not a hard trust-region guarantee

PPO reuses a recent on-policy batch for several epochs. With probability ratio \(\rho_t=\pi_\theta(a_t\mid s_t)/\pi_{\mathrm{old}}(a_t\mid s_t)\), advantage \(\hat A_t\), and clip width \(\epsilon\), its common surrogate is $$ L^{\mathrm{clip}}= \mathbb E\left[\min\left(\rho_t\hat A_t, \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\right)\right]. $$ Clipping removes incentive from some overly large ratio moves. It does not impose a hard KL bound or guarantee monotonic improvement; implementations still monitor approximate KL, entropy, clipping fraction, value error, and held-out performance.

11.4 Exploration — the bandit laboratory

Bandits and regret — isolate the exploration problem

A \(K\)-armed bandit has no state transition: each arm has an unknown reward distribution. If \(\mu^*=\max_a\mu_a\), pseudo-regret after \(T\) pulls is \(\sum_{t=1}^T(\mu^*-\mu_{a_t})\). Regret measures the opportunity cost of learning. It differs from realized reward noise and depends on assumptions such as stationarity.

\(\varepsilon\)-greedy and UCB — random exploration versus optimism

\(\varepsilon\)-greedy chooses a random arm with probability \(\varepsilon\), otherwise a current empirical best. Constant \(\varepsilon>0\) keeps exploring forever and generally gives linear regret in a stationary bandit; schedules can decay. UCB chooses an optimistic index such as \(\hat\mu_a+c\sqrt{\ln t/n_a}\). Under appropriate stationary bounded or sub-Gaussian reward assumptions, classical UCB variants achieve logarithmic expected regret. The constant and formula are algorithm definitions, not universal defaults.

Thompson sampling — act according to posterior uncertainty

For Bernoulli rewards and a \(\operatorname{Beta}(\alpha,\beta)\) prior, \(s\) successes and \(f\) failures give posterior \(\operatorname{Beta}(\alpha+s,\beta+f)\). Thompson sampling draws one possible success rate per arm and chooses the largest. Poor priors eventually wash out under sufficient data, but model misspecification, delayed outcomes, censoring, and nonstationarity can invalidate the tidy posterior story.

11.5 RLHF — reinforcement learning meets language models

Language models as policies — map the abstraction carefully

In token-level RL, context is state, the next token is an action, and the generated response is a trajectory. A terminal sequence reward can be assigned back to many token decisions. This mapping is useful, but the environment includes prompts, tools, users, and deployment feedback—not merely a static vocabulary. Offline preference training and online interaction therefore answer different distributional questions.

RLHF pipeline — supervised start, reward model, constrained optimization

  1. Supervised fine-tuning: fit demonstrations to obtain a capable reference/start policy.
  2. Preference collection: compare responses under a documented rubric and sampling policy.
  3. Reward modeling: fit a scalar preference predictor, often with a Bradley–Terry loss.
  4. Policy optimization: sample responses, score them, and optimize with PPO or another method while controlling drift from a reference.
  5. Evaluation: use held-out human judgments, safety tests, and distribution slices; proxy reward alone is not success.
RLHF_LOOP:
  start from supervised policy and frozen reference
  repeat:
    sample prompts and policy responses
    score responses with reward model
    form reward minus reference-divergence penalty
    estimate advantages and update policy with PPO
    stop or adjust when KL, reward, safety, or human evaluation drifts
  evaluate on preference, capability, and safety suites

Reward models — pairwise probability is not ground truth

A common model assigns scalar scores and fits \(P(y_w\succ y_l)=\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))\). Pairwise labels are easier than absolute scores in some settings, but they can be inconsistent, position-biased, culturally narrow, or noisy. The reward model interpolates those labels; optimizing it out of distribution can exploit its errors.

Guided calculation — Bradley–Terry preference
Convert a reward-score difference into preference probability and negative log-likelihood.

A score gap is relative within the comparison model; it is not a calibrated utility unit.

PPO with KL control — optimize a proxy without leaving its evidence

A simplified sequence objective is \(\mathbb E[r_\phi(x,y)-\beta D_{\mathrm{KL}}(\pi(\cdot\mid x)\Vert\pi_{\mathrm{ref}}(\cdot\mid x))]\). In practice the KL term may be estimated token by token and its coefficient adapted. It discourages large drift into regions where the reward model has little evidence. It cannot guarantee safety, remove reward hacking, or substitute for human evaluation.

Guided calculation — reward minus KL penalty

Default: A scores \(1.25\), B scores \(1.10\); the higher raw reward does not win after the illustrative penalty.

DPO — classify preferences relative to a reference policy

DPO uses preference pairs without fitting a separate explicit reward model or running an online PPO loop. For chosen \(y_w\), rejected \(y_l\), reference \(\pi_{\mathrm{ref}}\), and scale \(\beta\), a common loss is $$ -\log\sigma\left(\beta\left[ \log\frac{\pi_\theta(y_w\mid x)}{\pi_\theta(y_l\mid x)} -\log\frac{\pi_{\mathrm{ref}}(y_w\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)} \right]\right). $$ It is an offline, reference-relative preference objective derived under modeling assumptions. It still depends on preference quality, pair coverage, reference choice, and \(\beta\), and is not a theorem that every DPO model is safer or better than every RLHF model.

Self-check

1. A robot camera omits battery level, although battery level changes motion dynamics. Which statement is most accurate?

c. A state must summarize information relevant to future transitions and rewards. An algorithm cannot manufacture the Markov property from an insufficient observation.

2. A continuing simulator cuts every rollout at 1,000 steps only to control compute. At the cutoff, a TD value target should usually:

b. External truncation differs from an MDP terminal state. If the time limit defines the actual task, include time in state and model the horizon explicitly.

3. Which statement correctly distinguishes value iteration from policy iteration?

d. Both are model-based dynamic-programming methods in this setting. Value iteration uses partial evaluation inside optimality backups; policy iteration separates evaluation and improvement.

4. For current \(Q=2\), reward \(1\), \(\gamma=0.9\), \(\alpha=0.5\), max next Q \(5\), and chosen next Q \(3\), the continuing Q-learning update gives:

a. Target \(=1+0.9(5)=5.5\); updated value \(=2+0.5(5.5-2)=3.75\). SARSA would use the chosen value and update to \(2.85\).

5. Which statement about DQN is defensible?

c. DQN is model-free and off-policy. Its engineering stabilizers are powerful, but they do not supply the tabular convergence theorem.

6. Why can a state-only baseline reduce REINFORCE variance without changing its expected gradient?

b. The baseline must not introduce uncorrected action dependence. A finite sample can still show a small mean change even though the expectation is unchanged.

7. PPO has old probability 0.20, new probability 0.26, advantage \(2\), and \(\epsilon=0.2\). The clipped surrogate contribution is:

d. The ratio is \(1.3\). Compare \(1.3(2)=2.6\) with \(1.2(2)=2.4\) and take the minimum.

8. Which exploration claim needs no missing qualification?

a. Regret theorems depend on their assumptions. Nonstationarity, delayed/censored feedback, and context can require a different design.

9. Candidate A has reward 1.4 and KL 0.3; B has reward 1.7 and KL 1.2. With \(\beta=0.5\), which has the larger reward-minus-KL score?

c. A gives \(1.4-0.5(0.3)=1.25\); B gives \(1.7-0.5(1.2)=1.10\). This scalar is still only an illustrative proxy objective.

10. Which comparison among reward-model-plus-PPO RLHF and direct preference objectives is most accurate?

b. The feedback shape, reference/anchor, and training loop differ. ORPO combines chosen-response likelihood with an odds-ratio penalty, while IPO changes the pairwise loss geometry. All inherit feedback-quality, coverage, and distribution-shift risks; none dominates without task evidence.
